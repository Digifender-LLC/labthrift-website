# A first file box (NAS) for one person

You can share files from the old laptop for a while. A NAS is the later box: a quiet machine with hard drives that keeps photos and backups in one place. Two drive bays and simple software if you just want backups that restore. More bays and a faster port if you already know you will run extra apps on it.

Start at [what you already have](<start-with-what-you-have>) if you don't have a file box yet. A USB drive on the old laptop is enough to learn. The empty NAS is the teaser price. The drives are the real bill. Budget NAS-rated 4–8 TB disks on top, then a spare. Anyone quoting a NAS without drive math is selling a chassis.

## What this is for

The first NAS is a backup target, not a Plex flex. If the copies are not automatic and off the laptop, you bought a toy. Put 10G on the shopping list only after 2.5G is actually full.

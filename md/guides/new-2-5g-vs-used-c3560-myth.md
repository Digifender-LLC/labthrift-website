# The $40 used Catalyst is still 1G

A used Catalyst 3560-class 24-port is still a gigabit box. The closet upgrade is a new fanless 8-port 2.5G on a 12 V brick.

This is not a rewrite of [when a $40 switch is a gift vs a 90 W heater](<used-vs-new>). That test still stands. This note is only the speed myth: a gray 24-port Catalyst does not feed a 2.5G NAS or a 2.5G mini PC. It is 1G copper with a loud or warm PSU story. The ports you actually want are on a new pizza brick.

The shopping list for which 2.5G box lives in [best 2.5G switch](<2-5g-switch>). Here the pick is the default unmanaged 8-port. If you need a paper lifetime warranty instead, that is the TRENDnet. If you need VLANs or a 10G DAC, that is a different post: see [lifetime vs SmartNet](<lifetime-warranty-vs-smartnet>) and [QSW-2104-2S](<qnap-qsw-2104-2s-closet>).

## Skip

Skip the used Catalyst 3560 / 3750 impulse for this job. No used street price here. The box is still 1G. The default fans are the heater case already covered in [used vs new](<used-vs-new>). Skip random 5-port toys with one 2.5G uplink and four leftover 1G ports.

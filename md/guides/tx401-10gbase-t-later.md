# When one copy fills the faster house port: the 10G copper card that ships a cable

When one copy already fills the faster house port (2.5G) and the file box talks 10G over a normal ethernet jack (10GBASE-T), this card is the copper upgrade. It ships a Cat6A lead. Skip it if both ends already have fiber-style cages.

When one copy already fills the faster house port (2.5G) and the file box talks 10G over a normal ethernet jack (10GBASE-T), this is the copper card. Still a later buy. Still not a switch. Stay on [2.5G copper](<2-5g-switch>) until a single flow is full. If both ends have cages, buy the [new 10Gtek 82599](<10gtek-x520-vs-tx201>) plus a [2 m DAC](<sfp-plus-dac-closet>) instead. If the included 1.5 m is too short, add [Monoprice / Cable Matters Cat6A](<cat6a-vs-cat5e-closet>).

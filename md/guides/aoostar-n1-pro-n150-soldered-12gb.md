# Skip the palm box whose 12 GB cannot grow: AOOSTAR N1 Pro

Skip the tiny living-room box whose memory cannot grow. Soldered RAM means memory you cannot add later. 12 GB is the trap. Buy one you can upgrade, or wait.

Skip the palm box whose 12 GB cannot grow. Soldered RAM means memory you cannot add later. 2.5G means faster house ethernet. AOOSTAR N1 PRO: Intel N150 4C/4T up to 3.6 GHz. 12 GB LPDDR5-4400 soldered. Dual I226-V 2.5G. Wi-Fi 5. USB-C PD + DP + HDMI (triple 4K). 35 W adapter / 12 V 3 A. Official US page listed **$175** for 12/512. EU last-batch 12/1 TB was $249 and sold out. Amazon 22 Aug 2026: `B0F387XH21` **$137** (12 GB / 256 GB); `B0F388KC4V` **$149** (12 GB / 512 GB). Use it as a tiny dual-NIC appliance or a second node. Don't use it as the Proxmox host you plan to grow. 12 GB is not 8 GB, and it is the same problem. The [roundup](<n100-mini-pc>) already set 16 GB as the floor; this post is the soldered-ceiling case. See [RAM ceiling / soldered traps](<n100-n150-ram-ceiling-soldered-traps>).

# Skip the soldered LPDDR5 listing; wait for upgradable RAM: Beelink Mini S13

Skip the 12 GB soldered listing. Soldered RAM means memory you cannot add later. Wait for the version where you can add RAM, or pick another box.

Skip the soldered LPDDR5 listing. Wait for a version where you can add RAM. Soldered RAM means memory you cannot add later. Both cards say Intel N150 (4C/4T, 3.6 GHz burst), dual HDMI 4K60, Wi-Fi 6, BT 5.2, one 2.5G RJ-45. The listing copy calls it “13th Gen Alder Lake-N150.” Twin Lake N150 is the N100 refresh; print the CPU string, not the marketing generation. Single NIC. VESA palm box, about 4.52 × 4.01 × 1.54 in on the LPDDR5 card. Not dual LAN. Not a 4-port appliance.

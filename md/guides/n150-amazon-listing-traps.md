# Match CPU, ports, and RAM before you click Buy on Amazon

Before you click Buy on Amazon, match the real CPU, the real network ports, and whether memory can be upgraded. Title slugs lie. Skip a listing that only wins on the title.

Match the real CPU, the real network ports, and whether memory can be upgraded before you click Buy on Amazon. Title slugs lie. Beelink and GMKtec reuse titles. ASINs have redirected. The same model name can be RTL8111H 1G or I226-V 2.5G. One GMKtec URL slug still says “G3 Plus / N150” while the live title is a Core i3. This is the junk-listing note. The chip compare stays on [the roundup](<n100-mini-pc>).

## Skip

Skip any listing you cannot match on all three: CPU string, NIC chip, RAM type (SO-DIMM vs soldered, and the GB number). Listings titled EQ13 that describe N150 are EQ14 bait: see the [EQ13 note](<beelink-eq13-n200-dual-1g>). Skip 8 GB soldered or 8 GB SO-DIMM as a default. Skip sending people to maker storefronts that are sold out at a list price that does not match street (GMKtec official G3 Plus was sold out at a $499.99 tag). When Amazon is a mess, buy from the maker page if that page is in stock: [bee-link.com EQ14](<https://www.bee-link.com/products/beelink-eq14-n150>), [protectli.com VP2430e](<https://protectli.com/product/vp2430e/>).

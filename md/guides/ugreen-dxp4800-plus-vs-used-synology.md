# New 10G in the chassis instead of a used Synology: UGREEN DXP4800 Plus

New 10G in the chassis instead of a used Synology for 10G. Official $620 diskless. Don't buy a used DS918+ off eBay. Maker software (UGOS) is the risk. Synology DSM is why you still pay for a new DS224+ or DS923+.

Want 10G in a new 4-bay file box, not a used Synology pulled off eBay. This is not a rewrite of [first NAS](<first-nas>), which already shortlists this box. This note is only the used-Synology temptation.

UGREEN NASync DXP4800 Plus diskless: Intel Pentium Gold 8505, 8 GB DDR5 (max 64 GB), four bays, 10GbE + 2.5GbE. Official **$619.99** (was $729.99, $110 off) on nas.ugreen.com / ai.ugreen.com. Amazon ASIN B0D22JRHZB. UGREEN lab power: **42.36 W** drive access / **18.12 W** drive hibernation (one Seagate 2 TB). Quiet mode **29–34 dB** (maker copy, not measured here). 2-year warranty. Has fans. Not a 1U. Synology DS923+ is often cited ~$600 before a 10G add-in card (UGREEN’s own compare). New DS224+ is $300 and still 1GbE (different job). See [new vs Renewed](<synology-cpo-vs-amazon-renewed>).

## Skip

Skip used DS918+ / DS920+ / DS1520+ eBay lots. Skip Amazon Renewed as Synology CPO. Skip treating UGOS as DSM. If the copies are not automatic, you bought a chassis. That rule is still in [first NAS](<first-nas>). Used-enterprise frame: [used vs new](<used-vs-new>).

# 1-foot Cat6 patch leads for the 12-port panel

The hop from [panel](<closet-cat6-patch-panel>) to switch is one foot, not the 7-foot cable that came in the router box. Buy short Cat6 leads in five colors so every hop says what it is at a glance. Pick Size 1 ft at checkout, and buy two 5-packs if the 12-port panel is full.

24 AWG bare copper, UTP, snagless boots, gold-plated RJ45. TIA/EIA 568-C.2. 550 MHz. 10GBASE-T on a short run. PoE / PoE+ / PoE++. Combo pack is black, blue, green, red, white, one color per job (NAS, AP, WAN, lab, spare). Same 24 AWG recipe as the 5-pack and 10-pack `160001` in a single color. This is not the 28 AWG ultra-slim `160019`.

Cable Matters store, 23 Aug 2026: 5-color combo `160021` **$9.99**. Solid-color 5-pack `160001` **$9.99**. 10-pack `160001` **$16.99** , pick 1 ft. Amazon 1 ft 5-color listing `B00HEM656U` printed $9.99 on one snap; Amazon did not return a clean buy box on this fetch. Print the live tag. Two 5-packs cover a 12-port panel with slack. One 10-pack is cheaper if every lead can be the same color.

## Skip

Skip the 7-foot “router kit” cable that puddles on the UPS. Skip CCA no-name 50-packs. Skip Cat8 for a 2.5G closet. Skip buying 3-foot leads “for slack”: that slack is a snag on the [1U shelf](<closet-1u-shelf>). Skip ultra-slim 28 AWG unless the door is the constraint. The in-wall run stays whatever you already punched; this note is only the panel-to-switch hop. Use [hook-and-loop](<closet-cable-management>), not a zip tie on the boot. I haven't fluked these.

# Cat6a vs Cat5e in a closet that already does 2.5G

2.5GBASE-T is specified to run on existing Cat5e. Don't rip walls.

Buy short Cat6a patch only for the 10G hop you will actually use, and only copper labeled pure bare copper: not CCA. The [2.5G switch](<2-5g-switch>) does not require a recable. If that hop is a [TX401](<tx401-10gbase-t-later>), the card already ships a 1.5 m Cat6A; add length only if that is too short.

## Skip

Skip ripping in-wall Cat5e for 2.5G. Skip CCA “Cat6” mystery packs. Skip buying a house of Cat6a because a future 10G card exists: that is a later note.

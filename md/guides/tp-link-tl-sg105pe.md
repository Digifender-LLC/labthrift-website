# Same quiet two-AP brick with VLAN menus when you need them: TP-Link TL-SG105PE

Web UI for VLAN, QoS, and PoE Auto Recovery. Skip it if you only need two radios powered.

Same quiet two-AP brick with VLAN menus when you need them. SKU `TL-SG105PE`. Five 1G RJ45. Ports 1–4 are 802.3af/at, 30 W each, **65 W** shared. Port 5 is data only. Easy Smart: web UI plus a Windows utility for VLAN, QoS, IGMP snooping, and PoE Auto Recovery. Fanless metal, 99.8 × 98 × 25 mm, wall-mount holes. External 53.5 VDC / 1.3 A brick. Maker idle 4.5 W, 75.2 W with a full 65 W PD load. 10 Gbps fabric, 7.44 Mpps, 2K MAC, 16 KB jumbo. Skip it if you only need two radios powered with no menus.

## Skip

Skip this if the job is two APs and an uplink with no VLANs. That is [SG1005P](<tp-link-tl-sg1005p>) for the same watts. Skip listings that photo an 8-PoE brick; this SKU has four PoE ports. Skip SG105E (no PoE). Skip SG105PP-M2 until the radios actually speak 2.5G. Skip 24 V passive injectors on 802.3af APs. Injector vs switch: [the two-AP note](<poe-injector-vs-switch-two-aps>).

# A label maker you will actually use on patch leads

Masking tape dies in a warm closet. Brother TZe laminated tape on a Bluetooth cube is the boring ID system: port, VLAN, and host name on every lead.

The Plus (24 mm) is the one if you also label the UPS and the rack rail. Pair with [hook-and-loop](<closet-cable-management>) so you can read the flag after you move a lead.

# New $49 faster puck, not a used gigabit US-8: UniFi Flex Mini 2.5G

New $49 faster puck for a UniFi desk, not a used gigabit US-8. Used US-8 and Flex Mini 1G lots are still one-gigabit boxes.

SKU `USW-Flex-2.5G-5`. Four 2.5GbE copper ports plus one 2.5GbE PoE-in for power. USB-C 5 V / 1 A brick in the box. Maker max **5 W** on the brick, **6.4 W** on PoE-in. Non-blocking 12.5 Gbps, switching 25 Gbps. UniFi Network 8.4.62 and later. Polycarbonate puck, not a 1U. No PoE out: it takes power, it does not feed APs.

UI store, 23 Aug 2026: **$49** / **$52 surcharge-incl.** Authorized Multilink printed **$52.15**. CDW printed **$64.99** on a 4–6 week card. Amazon [`B0CPT3K48S`](<https://www.amazon.com/Switch-UBIQUITI-USW-Flex-2-5G-5-UNIFI-2-5GB/dp/B0CPT3K48S>) was a third-party card at **$72.19** whose model string still said Flex Mini. Print the live tag. Buy the store.

## Skip

Skip used US-8, US-8-60W, and Flex Mini 1G lots. Still 1G. Skip Amazon third-party cards at $72–$78, and skip any listing whose model string still says Flex Mini on a 2.5G SKU. Skip this puck if you needed PoE out. That is [USW-Ultra](<unifi-usw-ultra-vs-used-catalyst-poe>). Skip it if you are not already UniFi; buy [SG105S-M2](<tp-link-tl-sg105s-m2>).

# New USB-C UniFi gateway, not a used USG plus Cloud Key: Cloud Gateway Ultra

New USB-C UniFi gateway with a built-in controller, not a used USG glued to a Cloud Key. Buy [UCG-Ultra](<https://store.ui.com/us/en/products/ucg-ultra>) new if the house is already UniFi. This is not Protect, and it is not a switch. See [USW-Ultra](<unifi-usw-ultra-vs-used-catalyst-poe>) for the PoE box.

UCG-Ultra: compact Cloud Gateway, 30+ UniFi devices / 300+ clients, 1 Gbps routing with IDS/IPS, multi-WAN load balance. Port layout is one 2.5GbE WAN and four 1GbE LAN. USB-C powered, adapter in the box. Maker max **6.2 W**. Quad Cortex-A53 1.5 GHz, 3 GB DDR4, 16 GB eMMC, 0.96" status LCD. UI store 23 Aug 2026: **$129** / **$139 surcharge-incl.** B&H printed **$136**. Newegg printed **$132**. Print the live tag. The Amazon card we fetched was a Generic listing at $189.99. Skip it.

## Skip

Skip used USG-3P and USG-Pro-4 lots. Skip Amazon Generic cards that don't say Ubiquiti. Skip Cloud Gateway Max until you need Protect or more than 1 Gbps IDS/IPS. Skip this whole page if you are not already UniFi. [Flint 2 in AP mode](<gl-mt6000-ap-mode-no-poe>) or [cheap PoE](<cheap-poe>) is the other door. This is a gateway, not the [fanless PoE switch](<unifi-usw-ultra-vs-used-catalyst-poe>).

# Read the network ports before you buy this N150 mini: Beelink EQ14

The same EQ14 name is sold with gigabit or faster 2.5G ports. Confirm which ports you are actually buying.

Confirm which network ports you are actually buying. Same EQ14 name, gigabit or faster 2.5G. 2.5G means faster house ethernet. The EQ14 is Beelink’s current N150 closet box that is not on the [S12 / S13 short list](<n100-mini-pc>): internal PSU (IEC cord, no brick), dual M.2 PCIe 3.0, one DDR4 SO-DIMM with an official max of 16 GB, claimed 32 dB fan, MSP 25 W. Official 16 GB ×1 DDR4 + 500 GB SSD was **$375** on bee-link.com 22 Aug 2026 (was $429).

Don't buy the 1G Realtek variant and treat it like a 2.5G firewall box. Confirm RTL8111H vs I226-V on the unit label. Then decide if you even want dual LAN, or if you need a [4× 2.5G appliance](<dual-lan-mini-vs-4x-2-5g-appliance>).

## Skip

Skip any “EQ14” click that does not name the NIC chip. Beelink ASINs have redirected on third-party sites; one search hit (`B0C339KVH9`) needs the title re-checked before anyone calls it EQ14. Skip 8 GB soldered configs as a default. This is not a 4-port firewall: see [Protectli VP2430e](<protectli-vp2430e-n150-4x-2-5g-proxmox>) or the [CWWK Amazon 4-NIC](<cwwk-n100-4x-i226-amazon>) for that class. For the older dual-2.5G N100 sibling, see [EQ12](<beelink-eq12-n100-dual-2-5g>). Listing roulette is collected in [N150 Amazon traps](<n150-amazon-listing-traps>).

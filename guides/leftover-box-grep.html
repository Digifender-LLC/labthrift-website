Notes / Faster network / Find a word in a file

Written 29 Aug 2026. This is a how-to, not a product card.

Find a word in a file

After SSH works, search a file with grep so you see only the matching lines. You don't need a file viewer app for this.

Read a file without opening the editor dumps the whole short file. Read a file one screen at a time pages through a long one. When you already know the word you care about, grep prints only the lines that have it. You are still only looking. The computer does not need a desktop, a search app, or a NAS for this one job.

Skip until SSH already works

SSH from the couch should already get you a prompt. If the file is short and you want every line, that is read a file without opening the editor. If the file is long and you want to turn pages, that is read a file one screen at a time. If a house job broke and you need the computer's own diary, that is when something broke, look at the log. Skip this whole note if you only need a house share other computers browse. That is a folder the house can open.

What this is

grep searches one file (or a few) for a word or short phrase. You run it on the computer, after SSH. Matching lines print to the SSH window. The file stays on disk. You are only looking. It does not open an editor. That is nano. It does not dump every line. That is cat. It does not take over the window like a pager. That is less. One word, same computer, only the hits.

Search a practice file

SSH in. Make a short throwaway file:

printf 'apple\nbanana\napple pie\ncarrot\n' > ~/fruit.txt

Then search for the word apple:

grep apple ~/fruit.txt

You should see two lines: apple and apple pie. The banana and carrot lines stay quiet. That is the whole first-night trick.

A real file that is safe to practice on:

grep ssh /etc/services

That list is already on Debian and Ubuntu. You are only looking. Don't edit it.

Useful extras, still looking only

Show line numbers so you can find the hit later:

grep -n apple ~/fruit.txt

Ignore capital letters if you are not sure how the file spelled it:

grep -i apple ~/fruit.txt

Count how many matching lines without printing them:

grep -c apple ~/fruit.txt

If you see command not found, install the usual tools, then try again:

sudo apt install grep

Debian and Ubuntu Server usually already have it. That install is not a reason to buy a search app.

When you are done practicing:

rm -i ~/fruit.txt

What this is not

This is not an editor. That is edit a file from the couch. It is not a dump of the whole file. That is read a file without opening the editor. It is not paging through every line. That is read a file one screen at a time. It is not the computer's system journal. That is when something broke, look at the log. It is not a list of names in one folder. That is see what's in a folder. It is not a hunt for a file by name across folders. That is find a file by name. It is not a house share other computers browse. That is a folder the house can open.

See what's in a folder. Need to change a line? Edit a file from the couch. Need a spare before you edit? Copy a file without leaving the computer. Need the throwaway gone for real? Forgot which folder holds the file? Find a file by name. When key login is boring on every computer you use, turn off password login once the key works. Keep SSH on the house network: keep the computer on the house network. Don't forward port 22.

Skip

  • Skip if SSH still fails. Finish SSH from the couch first.
  • Skip cat on a long file when you only care about one word. That dump is the wrong tool for a hunt.
  • Skip nano if you only want to find a line. That tool is for changing a line.
  • Skip grep on photos, zip files, or programs. Those print junk. A text file is the job.
  • Skip recursive folder hunts and fancy regex on day one. One file, one plain word is enough.
  • Skip buying a search app, a “cloud IDE,” or a NAS to find one word in a text file.
  • Skip SSH settings, /etc/shadow, and anything under /etc/ssh. Looking at trusted laptop keys is see which laptop keys the computer already trusts.
  • Skip opening SSH to the internet so you can search files from a coffee shop. That is keep the computer on the house network.

New Wi-Fi 7 gateway, not a used Dream Router: UniFi Express 7

New Wi-Fi 7 gateway for a UniFi house, not a used Dream Router. Used UDR and original Express lots are still Wi-Fi 6 with gigabit copper. The new UX7 is a USB-C Cloud Gateway with Wi-Fi 7, a 10G WAN, and a faster LAN. UI store $199 / $214 surcharge-incl. Buy that if the house is already UniFi and you want the radio in the gateway. Need Protect or more LAN? That is Dream Router 7, not a used UDR.

SKU UX7. Compact desktop, 117 × 117 × 42.5 mm, 422 g. One 10 GbE RJ45 WAN, one 2.5 GbE RJ45 LAN. IDS/IPS 2.3 Gbps. UniFi Network only, no Protect. Maker says 30+ UniFi devices / 300+ clients. Tri-band Wi-Fi 7 (2×2), coverage claim 1,750 ft². USB-C 5 V / 5 A, adapter in the box, max 22 W. Quad Cortex-A53 1.5 GHz, 3 GB RAM, 0.96" status LCD. Can run as a mesh AP. This is not a switch. See UCG-Ultra for the wired USB-C gateway, and USW-Ultra for PoE.

UI store, 23 Aug 2026: $199 / $214 surcharge-incl. Add to cart was live on fetch. B&H printed $199 on the UX7-US card. Print the live tag. Skip Amazon third-party cards that don't say Ubiquiti.

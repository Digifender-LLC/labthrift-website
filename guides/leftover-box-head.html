Notes / Faster network / See the start of a file

Written 29 Aug 2026. This is a how-to, not a product card.

See the start of a file

After SSH works, print the first lines of a file with head so a long file does not flood the window. You don't need a file viewer for this.

Read a file without opening the editor dumps the whole short file. Read a file one screen at a time pages from the top. See the end of a file prints the newest lines at the bottom. When you only care about the opening lines, head prints those and stops. You are still only looking. It does not need a desktop, a file viewer, or a NAS for this one job.

Skip until SSH already works

SSH from the couch should already get you a prompt. If the file is short and you want every line, that is read a file without opening the editor. If you want the newest lines at the bottom, that is see the end of a file. If you want to turn pages from the start, that is read a file one screen at a time. Skip this whole note if you only need a house share other computers browse. That is a folder the house can open.

What this is

head prints the first lines of a file. You run it on the computer, after SSH. The file stays on disk. You are only looking. It does not dump every line. That is cat. It does not take over the window like a pager. That is less. It does not print the end. That is tail. It does not search for a word. That is grep. It does not ask what kind of file this is. That is file. One path, same computer, only the start.

Print the first lines

SSH in. Make a throwaway file that is long enough to have an obvious start:

seq 1 40 > ~/lines.txt

Then print the first lines:

head ~/lines.txt

You should see 1 through 10. With no extra flags, head prints the first ten lines and stops. That is the whole first-night trick.

A real file that is safe to practice on:

head /etc/services

That list is already on Debian and Ubuntu. You are only looking. Don't edit it.

Useful extras, still looking only

Ask for a different count:

head -n 5 ~/lines.txt

That prints the first five lines. Swap the number if you want more or fewer.

Need the last lines instead? That is see the end of a file. Need a line count before a dump? That is see how long a file is. Need to know if the path is even text? That is see what kind of file this is.

If you see command not found, install the usual tools, then try again:

sudo apt install coreutils

Debian and Ubuntu Server usually already have it. That install is not a reason to buy a file viewer.

When you are done practicing:

rm -i ~/lines.txt

What this is not

This is not a dump of the whole file. That is read a file without opening the editor. It is not paging through every line from the top. That is read a file one screen at a time. It is not a peek at the last lines. That is see the end of a file. It is not a line count. That is see how long a file is. It is not asking what kind of file this is. That is see what kind of file this is. It is not a compare of two files. That is see whether two files are the same. It is not a search for a word. That is find a word in a file. It is not a hunt for a file by name. That is find a file by name. It is not an editor. That is edit a file from the couch. It is not a house share other computers browse. That is a folder the house can open.

Skip

  • Skip if SSH still fails. Finish SSH from the couch first.
  • Skip cat on a file that never stops when you only care about the opening lines. That dump is the wrong tool for a peek at the start.
  • Skip head on photos, zip files, or programs. Those print junk. A text file is the job. Ask first with see what kind of file this is.
  • Skip head if you already know the path is a short text note you made tonight. That is read a file without opening the editor.
  • Skip buying a file manager, a “cloud IDE,” or a NAS to read the start of one text file.
  • Skip SSH settings, /etc/shadow, and anything under /etc/ssh. Looking at trusted laptop keys is see which laptop keys the computer already trusts.
  • Skip opening SSH to the internet so you can peek at files from a coffee shop. That is keep the computer on the house network.

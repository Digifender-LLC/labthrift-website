See how long a command took

After timeout, see how long a command took with time. You don't need extra software for this.

Stop a command after a few seconds gave a command a time limit. Tonight you time a command: time. Time runs a command, then prints how long it ran. You are still only practicing in home on the computer. It does not need extra system software, htop, Grafana, or a NAS for this one job.

Skip until SSH already works

SSH from the couch should already get you a prompt. If a time limit is what you want, that is stop a command after a few seconds. If the clock read is what you want, that is see what time the computer thinks it is. If re-run until you stop is what you want, that is see change without typing again.

What this is

time times a command. You type time, then the command. After it finishes, time prints real, user, and sys. Real is wall-clock. Start with time sleep 2. It is not date. Date reads the clock. It is not timeout. Timeout stops a command. Lid sleep is a different job: don't let the old laptop sleep.

Practice time in home

SSH in. Make sure home is where you sit:

pwd

You want a path that ends in your login name. If not:

cd ~

Time a two-second wait:

time sleep 2

You want the wait, then a short timing report. Real should be about two seconds. That is enough for tonight. Practice only in home.

Debian and Ubuntu shells already have time. Don't make apt the job.

Useful extras, still home only

Optional: a command that returns at once:

time true

Optional: time a listing:

time ls

Optional: POSIX format:

time -p sleep 2

Don't make -p required. You can stop at time sleep 2.

What this is not

This is not timeout. That is stop a command after a few seconds. It is not date. That is see what time the computer thinks it is. It is not watch. That is see change without typing again. It is not lid sleep. That is don't let the old laptop sleep. It is not what is busy. That is see what is keeping the computer busy. It is not opening SSH to the internet. That is keep the computer on the house network. Don't forward port 22.

What next

Need a time limit? Stop a command after a few seconds. Need the clock? See what time the computer thinks it is. Need a month grid? See the month on a calendar. Keep SSH on the house network: keep the computer on the house network. Don't forward port 22.

Skip

  • Skip if SSH still fails. Finish SSH from the couch first.
  • Skip timeout, date, watch, and lid sleep as tonight's job. Those pages already exist.
  • Skip timing /, /etc, or a huge dump. Tonight: time sleep 2.
  • Skip files under /etc, SSH folders, or paths you don't own. Practice only in home.
  • Skip rm -rf. Careful delete only: delete a file carefully.
  • Skip opening SSH to the internet so you can do this from a coffee shop. That is keep the computer on the house network. Don't forward port 22.

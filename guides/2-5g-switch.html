A faster switch for a first home lab

You don't need a new switch to start a home lab. Plug the old laptop into the router you already have. Buy a faster switch later, if file copies actually crawl.

When that day comes, those extra-fast ports are called 2.5G, a bit more than twice the speed of the old gigabit ports on most routers. They still use the ethernet cables you already have. Most first labs stall because one old switch is the bottleneck. Start here, then worry about 10G later.

Skip

Skip random no-name 5-port toys that only have one fast port and four leftover slow ones. Skip a computer stuck at 100. Check the cable speed first: see the cable speed. Skip a $400 brand-name PoE monster until you have access points that need that budget. Skip a used old gigabit office switch for this job. The whole point is the faster ports.

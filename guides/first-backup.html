A backup of the house folder

A second copy of the house folder, on a USB disk you already have, or on another old PC. You don't need a NAS for this.

The share on this computer is useful the day that computer dies, only if a second copy exists. That second copy is a backup. Same computer. Same SSH from the couch.

What this is

A program called rsync. A tool already on Debian and Ubuntu that copies a folder and, next time, only copies what changed. You don't buy Synology Backup or a cloud plan for a folder of photos.

This assumes the share from a file share, or any folder you care about, like /srv/share. Debian or Ubuntu Server, the OS from what OS to put on it, installed as in your first weekend. SSH in from the couch.

Where the copy lives

Where the copy livesWhen to pick it
A USB disk you already haveThe default. Plug it in, copy, unplug. You don't need a second computer.
Another old PC on the house networkYou already did the first weekend on that computer too, so SSH already works.

USB disk you already have

Plug the disk into the computer. Find it with lsblk. That is a list of disks. It often shows up as /dev/sdb1. Use the name lsblk actually printed, not a guess.

lsblk

Mount it, which means make the USB disk show up as a folder:

sudo mkdir -p /mnt/backup && sudo mount /dev/sdb1 /mnt/backup

No partition, mount fails, or you want a clean Linux filesystem on a spare stick first? That wipe-and-format walk is format a USB stick for the house backup.

Then copy the share:

rsync -a /srv/share/ /mnt/backup/share/

The trailing slashes matter. They tell rsync to copy the contents of the share into that backup folder. Leave both slashes on.

Another old PC

If you have a second old PC on the house network, the short version is copy over SSH:

rsync -a /srv/share/ otheruser@other-address:share-backup/

Swap otheruser and other-address for the login and address of that second box. Trailing slashes still matter, same as the USB copy. For the full walk (prove SSH, make a landing folder, dry-run, check it landed), see copy the house folder to another old computer.

After the copy

Before you trust it, look on the USB (or the second box) and confirm files landed: check that the backup actually copied. Copy fails or the stick vanished? When the house backup won't run.

If you used the USB disk, unmount it before you yank the cable:

sudo umount /mnt/backup

Leave the disk unplugged most of the time. A problem on this computer cannot also wipe a copy that is sitting in a drawer. Fuller walk (sync, target is busy, remount next week): unplug the backup USB safely.

Do it again next week

Same command. rsync will skip files that did not change, and copy the ones that did. A reminder on your phone is enough for now. After one manual copy worked, this computer can run that same rsync every week: back up the folder every week without remembering.

What next

Before you trust one old drive with the only copy, see if the old disk is dying. Spare stick needs a wipe first: format a USB stick for the house backup. Unmount before the drawer: unplug the backup USB safely. See the USB disk first: see if the USB backup disk showed up (or the fuller disk list: see disks and USB sticks on the computer). Confirm the copy landed: check that the backup actually copied. If rsync fails: when the house backup won't run. Stick full: when the backup USB is full. Then copy one file back: restore one file from the USB backup. Then leave it. Use the folder, and copy it again next week. A Mac can also back up overnight to a separate share: Time Machine to the house share. A VM is this note, still later. Not a NAS. Not RAID. Not Backblaze on day one. Full folder back after a wipe: put the house folder back from the backup.

Optional: jot what you back up and where in Lab plan — username + passkey, no email. Skip if you just want to keep reading.

Skip

  • Skip buying a NAS for backups. The USB disk you already have is enough.
  • Skip RAID. RAID is not a backup.
  • Skip restic and Borg on day one.
  • Skip a cloud plan until the USB copy exists.
  • Skip the 3-2-1 lecture.
  • Skip leaving the USB plugged in forever.

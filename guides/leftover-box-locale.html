Notes / Faster network / See language and region

Written 31 Aug 2026. This is a how-to, not a product card.

See language and region

After printenv, print language and region with locale so character encoding makes sense. You don't need extra software for this.

See HOME and PATH printed login environment. Tonight you check language and region: locale. Locale prints LANG and related settings. You are still only practicing in home on the computer. It does not need extra system software, htop, Grafana, or a NAS for this one job.

Skip until SSH already works

SSH from the couch should already get you a prompt. If HOME and PATH are what you want, that is see HOME and PATH. If the clock zone is what you want to set, that is set the clock to your house. If the clock read is what you want, that is see what time the computer thinks it is.

What this is

locale prints language and region. You type locale. LANG is the language and region string. Charmap is how characters are encoded. It is not timezone. Timezone sets the clock zone. It is not date. Date reads the clock. It is not printenv. Printenv prints HOME and PATH.

Practice locale in home

Debian and Ubuntu usually already have locale. Don't make apt the job.

Useful extras, still home only

Optional: LANG only:

locale LANG

Optional: character map:

locale charmap

Optional: LANG from the environment:

printenv LANG

That is printenv, not locale. Printenv is see HOME and PATH. Skip changing locale tonight. Tonight you take a look.

What this is not

This is not printenv. That is see HOME and PATH. It is not timezone. That is set the clock to your house. It is not date. That is see what time the computer thinks it is. It is not cal. That is see the month on a calendar. It is not OS name. That is see which OS the computer is already running. It is not opening SSH to the internet. That is keep the computer on the house network. Don't forward port 22.

What next

Need HOME and PATH? See HOME and PATH. Need the terminal name? See the terminal name. Need the clock? See what time the computer thinks it is. Keep SSH on the house network: keep the computer on the house network. Don't forward port 22.

Skip

  • Skip if SSH still fails. Finish SSH from the couch first.
  • Skip changing locale tonight. Tonight you take a look.
  • Skip timezone, date, cal, and printenv as tonight's job. Those pages already exist.
  • Skip files under /etc, SSH folders, or paths you don't own. Practice only in home.
  • Skip rm -rf. Careful delete only: delete a file carefully.
  • Skip opening SSH to the internet so you can do this from a coffee shop. That is keep the computer on the house network. Don't forward port 22.

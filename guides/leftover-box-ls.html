Notes / Faster network / See what's in a folder

Written 28 Aug 2026. This is a how-to, not a product card.

See what's in a folder

After SSH works, list the folder you are sitting in with ls. You don't need a file manager app for this.

SSH from the couch puts you at a prompt. You are sitting in a folder. ls prints the names in that folder. That is how you confirm a copied file landed, pick a file for nano, and stop guessing. The computer does not need a desktop, a file manager, or a NAS for this one job.

Skip until SSH already works

SSH from the couch should already get you a prompt. A short name is nicer: give the computer a short name on your laptop. If you only need to move a file, that is copy a file to the computer from your laptop. If you are changing a file, that is edit a file from the couch. This note is how you look at names. Skip this whole note if you are still stuck on the first login.

What this is

ls lists names in a folder. Leave off a path and it lists the folder you are already in. After a normal SSH login that is your home folder (the login’s own files). You are not measuring free disk. That is see if the computer still has room. You are not ranking which folders are huge. That is see which folders are eating the disk.

List the folder you are in

SSH in. At the prompt:

ls

You get a list of names. Folders and files sit together. If the list is empty, you are in a fresh home folder. That is fine. You have not broken anything.

See where you are

If you are not sure which folder that list belongs to:

pwd

That prints the full path. The dedicated note is see which folder you are in. A first login is usually something like /home/you. The tilde ~ is a short name for that home folder. Optional same list, named:

ls ~

If you are already home, that is the same names as plain ls.

Optional: sizes and dates

After you copy a file over, you want more than a name:

ls -lh

-l is the long list (size, date, who owns it). -h makes sizes readable (12K, 3.1M) instead of raw bytes. Look at one name:

ls -lh ~/photo.jpg

You want the filename, a size that is not zero, and today’s date if you just copied it. Swap the filename for yours.

Optional: names that start with a dot

ls hides names that start with a dot. Those are ordinary files the computer uses for settings. ~/.ssh is one of them. Seeing which laptop keys already live there is see which laptop keys the computer already trusts. To include those names:

ls -a

or the long form:

ls -lah

Skip deleting anything you don't recognize in that list.

Look at a folder you name

You can point ls at a folder without moving:

ls /etc

That is the settings folder. It is long. You are only looking. Don't edit those files from this note. Optional one folder you copied into:

ls ~/scripts

If you see no such file or directory, the folder is not there yet. Check the name, or make a folder. That is not a reason to buy a NAS.

What this is not

This list is names. It is not a backup. It is not a house share other computers browse. That is a folder the house can open. Free disk left is see if the computer still has room. Which folders are huge is see which folders are eating the disk.

What next

Not sure which folder that list belongs to? See which folder you are in. Need a folder that is not there yet? Make a folder. Need to sit in one of those folders? Move into a folder. Forgot which folder holds the file? Find a file by name. Need to change one of those files? Edit a file from the couch. Need the file on the laptop too? Copy a file to the computer from your laptop. Tired of retyping the same long line? Reuse a command you already typed. When key login is boring on every computer you use, turn off password login once the key works. Keep SSH on the house network: keep the computer on the house network. Don't forward port 22.

Skip

  • Skip if SSH still fails. Finish SSH from the couch first.
  • Skip buying a file manager, Midnight Commander, or a “cloud drive” app to see names.
  • Skip ls -R / tonight. That dumps the whole the computer and is not a backup.
  • Skip deleting names you don't know. Looking is the job.
  • Skip opening SSH to the internet so you can list folders from a coffee shop. That is keep the computer on the house network.

Getting started · 6 of 9

Written 23 Aug 2026. This is a how-to, not a product card.

The first useful thing

Put a house-wide ad block on the old PC. The rest of the house keeps using the internet as usual. You don't need a Raspberry Pi.

You already have a computer that stays on. SSH from the couch works. The next job is one useful thing for the house, not a new gadget.

What this is

A program called Pi-hole. It answers name lookups for the house and skips the ones that are ads. Phones and laptops don't need an extra app. You point the house at this box once.

DNS is the phone book that turns names into numbers. When a laptop asks for a site, something has to look up the number. Pi-hole is one free program that sits in that phone book and skips ad names. Real sites still go through. A lot of ads never load.

You don't buy a Raspberry Pi. The OptiPlex or old laptop is already a computer that stays on. Pi-hole is just software on it. The name sounds like a tiny board. Ignore that. You already did the hardware part.

Install it on the computer

This assumes Debian or Ubuntu Server, the OS from what OS to put on it, installed as in your first weekend. SSH in from the couch.

The house has to find this computer later, so give it a static-ish address. A DHCP reservation is the easy way: tell the router to always give it the same number. Use the address you found on the first weekend. If you skip this, it might get a new number after a reboot, and the house will look in the wrong place.

The official path is one command from pi-hole.net. Walk through the prompts. Take the defaults. Use the URL on their site, not a copy from a forum. The basic install docs are the page to follow.

On the computer, run:

curl -sSL https://install.pi-hole.net | bash

If it asks for sudo, that is normal. Note the admin password it prints. You will need it in a minute.

Open the page it prints

The installer prints a web address. Open it on your normal computer. Usually http://pi.hole/admin, or that computer's address plus /admin. You will see a dashboard. That is enough for tonight. Don't start hunting extra block lists.

Point the house at it

On the router, set DNS to this computer's address so every phone and laptop asks it for names. Full steps: point the house at the ad block. Brand menus: point common home routers at Pi-hole. If ufw is already on for this computer, allow DNS there too: turn on a simple firewall without locking yourself out.

What next

Leave it a week. First, change the printed admin password. Then see what Pi-hole blocked so you know it is working. If the admin opens but totals stay at zero, see when Pi-hole shows no queries. Then maybe a file share on this same computer. If it is still on house Wi-Fi, put it on a cable first: a cable beats Wi-Fi for the computer. Once a week, keep Pi-hole updated (apt alone does not). Before a reinstall or a big list change, save a Pi-hole backup. Tired of typing the number? Add a local name in Pi-hole. Phones still show ads right after you set router DNS? Flush old DNS on phones and laptops. If ads come back later, start with when ads come back. If only one phone stays dirty, see when one phone still shows ads. Guest SSID still shows ads? See when guest Wi-Fi still shows ads. Need a five-minute off switch? Pause Pi-hole for a few minutes. If one site you need is broken while ads stay gone, see when a site won't load after Pi-hole. Want to deny a domain on purpose? Block a site in Pi-hole on purpose. If the dashboard itself won't load, see when the Pi-hole admin page won't open. Waiting is fine. Not Kubernetes. Not a new mini PC.

Optional: track the first service you leave on in Lab plan — username + passkey, no email. Skip if you just want to keep reading.

Skip

  • Skip buying a Raspberry Pi “because Pi-hole.”
  • Skip Docker if you are not already using it. A bare install is fine on a dedicated old PC.
  • Skip Unbound on day one.
  • Skip blocking so hard that banking sites die.
  • Skip a second box for this.

Notes / Faster network / Change the login password

Written 26 Aug 2026. This is a how-to, not a product card.

Change the login password

Once SSH from the couch works, set a password you chose. Do this before you leave the install password sitting around.

You can already log in from the couch. Before you lean harder on that login, or turn on more services, replace the password from install day with one you chose.

Skip until SSH works

If you cannot log in yet, stop. That is SSH from the couch. Forgot the password entirely? When you forgot the computer's login password. This note assumes you can type commands on the computer from the couch.

What this is

You are changing the user password only. That is the password SSH asks for until you move to a key. Changing it does not change the Wi-Fi password. It does not change the router password. It is not the Pi-hole admin password, unless you set those the same on purpose. It is not the Samba share password. That is set or change the house-share password. The share itself is a file share on the computer.

Change it while logged in

SSH in the way SSH from the couch taught you. Then run:

passwd

It asks for the current password, then the new one twice. Nothing shows as you type. That is normal. Pick a password you chose, not the one from install day.

Open a second window before you leave

Keep the first SSH session open. Open a second SSH window and log in with the new password:

ssh you@that-address

Swap you and that-address the way SSH from the couch taught you. If the new password fails, you still have the old session open. Don't close the first window until the second login works.

What next

If this computer came from Marketplace, look for leftover accounts next: see if the computer still has old login accounts. When password login has been boring for a bit, log in with a key, not the password every time. Later, turn off password login once the key works. Don't open port 22 to the internet. SSH stays on the house network. That is keep the computer on the house network.

Skip

  • Skip this note if SSH from the couch does not work yet. That is SSH from the couch.
  • Skip changing the router password here.
  • Skip a password manager appliance.
  • Skip opening SSH to the internet.
  • Skip fail2ban on day one. Later is slow down password guesses on SSH.

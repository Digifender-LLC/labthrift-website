See which OS the computer is already running

Before you reinstall or buy a tiny computer, check which OS the computer already has.

An OS is the software the computer boots into. Windows, macOS, Debian, Ubuntu. What OS to put on the computer is the pick before you install. This note is the look after: what is already on it. Don't wipe a working computer because you forgot the name. Don't buy an N100 this morning because you are not sure.

Skip until SSH works

If ping fails and SSH hangs, start with is the computer still on? If you have never logged in from the couch, that is SSH from the couch. If you have not installed anything yet, start with what OS to put on the computer, then your first weekend with the computer. This note assumes you can log in from the couch, or sit at the keyboard.

What this is

A look, not a shopping trip. You are reading a small file the computer already keeps, so you know the name of the OS. You are not installing a second OS. You are not buying a tiny computer. You are not wiping the disk tonight. Kernel name is uname, not distro name. That is see kernel name and architecture. printenv is HOME and PATH (login environment), not distro name. That is see HOME and PATH.

Ask which OS it is

SSH in from the couch, or sit at the keyboard, then ask:

cat /etc/os-release

Point at the PRETTY_NAME= line. That is the name you can read. It often looks like Debian GNU/Linux 12 (bookworm) or Ubuntu 24.04 LTS. Debian or Ubuntu means this note applies. Weekly fixes from here are keep the computer updated.

Optional second look

If you want one spoken line instead of the whole file:

hostnamectl

Point at Operating System. That is the same name, in a shorter print. The name on the house network is a different line. That name is give the computer a name that sticks. Keep this light. Don't install extra tools for this look.

If the file is missing

No /etc/os-release usually means this computer is still Windows, or it is not a Debian-family Linux. Don't wipe it this morning. If you still use that laptop as a laptop, leave the OS it has. That pick is what OS to put on the computer. A tiny computer is later: a tiny computer you can leave on, when the computer is actually in the way.

If it already says Proxmox

You skipped ahead. You don't need to reinstall Debian tonight to “do it right.” House ad block and a file share can still live on that computer. The VM idea stays what a VM is, and when you don't need one. Whether the chip can even do VMs is see if the computer can run a pretend computer.

What next

If the name is Debian or Ubuntu, leave it. Weekly habit: keep the computer updated. Worker count before you shop: see how many workers the computer already has. The first rule stays start with what you already have. The later buy is a tiny computer you can leave on, when you actually need it.

Skip

  • Skip if SSH fails. That is is the computer still on? or SSH from the couch.
  • Skip kernel name as tonight. Uname is kernel, not distro name: see kernel name and architecture.
  • Skip printenv as tonight. Printenv is HOME and PATH, not distro name: see HOME and PATH.
  • Skip wiping a working computer because you forgot the OS name.
  • Skip buying an N100 because you were not sure which OS was on it.
  • Skip a NAS for this look.
  • Skip Proxmox tonight if the computer already has Debian or Ubuntu. That is what a VM is, and when you don't need one.

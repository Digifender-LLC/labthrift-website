Notes / Getting started / Is the computer still on?

Written 25 Aug 2026. This is a how-to, not a product card.

Is the computer still on?

You left the computer on. This morning ads are back, or SSH hangs. Check if it is awake before you buy anything.

Ping is a knock to see if the computer answers. That is a thirty-second check from the couch. Distinct from finding the address the first time. A new router will not help.

Skip this if SSH already works

If you can already SSH from the couch, the computer is on. That is the whole test. You don't need this note.

Knock from another computer

From another computer on the house network, in Terminal, knock three times:

ping -c 3 lab

If you used an address instead of a name, swap lab for the number from find the computer on the house network. On Windows, use ping lab and stop it after a few replies. If ping answers, the computer is on. Then SSH from the couch.

If ping fails

The computer may be asleep, cooked, off the cable, or actually off. Don't start with a new router. Check these:

  • A laptop lid put it to sleep. That is don't let the old laptop sleep.
  • The old laptop battery died because the charger was loose. That is see if the old laptop is actually plugged in.
  • It is buried under clothes or in a closed cabinet. That is don't cook the computer.
  • House Wi-Fi dropped. That is a cable beats Wi-Fi for the computer.
  • You shut it off last night. That is shut down the computer without yanking the plug. Press the power button once, then ping again.
  • It is in soft-off and you want to wake it from the couch. That is wake the computer from the house network.

A phone can tell you too

A phone on the house network still blocking ads means the computer is doing work. If ads came back, DNS may have fallen to the router. Point the house at the computer again in the first useful thing on the computer. If the computer is awake and banners are still back, check Pi-hole in when ads come back, check the ad block.

What next

Lights blinked and the whole house came back messy? after the power comes back. Want it to power itself next blink? Turn the old PC back on after a power blip. If it is soft-off on purpose, wake it with wake the computer from the house network. Packet fails? when Wake-on-LAN won't wake the computer. If ping answered and SSH still fails, walk when SSH won't connect. If ping answered and SSH works, you are done. To see how long it has been awake, not only that it answers, use see how long the computer has been awake. When the computer is awake again, confirm the three house jobs: after a reboot, check the computer still does its jobs. If ping needed the number, not lab, give the computer a name that sticks. If it has been a week, keep the computer updated. Don't buy a NAS. Don't buy a monitoring box. Soft restart without a full reboot: restart Pi-hole or the house share.

Skip

  • Skip this note if you can already SSH from the couch.
  • Skip a new router.
  • Skip a monitoring appliance, a UPS, and a new switch this pass.

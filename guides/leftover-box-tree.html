Notes / Faster network / See folders as a tree

Written 30 Aug 2026. This is a how-to, not a product card.

See folders as a tree

After SSH works, tree shows nested folders so you can see what is inside without clicking around. You don't need a file manager for this.

Unpack a zip you already have unpacks a zip. See what's in a folder lists one folder. Tonight you see nested folders as a tree. After unpack of a zip or tar, nested folders are hard to see with one ls. tree draws nested folders so you see what is inside without clicking around. You don't need a file manager, Finder, Explorer, Nautilus, or a NAS browser for this.

Skip until SSH already works

SSH from the couch should already get you a prompt. If you just unpacked a zip, that is unpack a zip you already have. If you only need names in one folder, that is see what's in a folder. Skip this whole note if you only need a house share other computers browse. That is a folder the house can open. Skip if you need a USB copy of the house folder. That is a backup of the house folder.

What this is

tree prints folders and files as a tree. You type tree, then a path in home. Nested folders are visible in one look. Start with a tiny practice folder, not a tree of whole home.

It is not a list of one folder. That is see what's in a folder. It is not a search by name. That is find a file by name. It is not unpack of a zip. That is unpack a zip you already have.

Show a practice tree in home

SSH in.

Make sure home is where you sit:

pwd

You want a path that ends in your login name.

If the path is wrong, run this:

cd ~

Make a tiny practice tree in home only:

mkdir -p ~/tree-me/a/b

echo hi > ~/tree-me/a/b/hi.txt

Show nested folders:

tree ~/tree-me

You want a, b, and hi.txt drawn as a tree.

If tree says command not found, install tree, then try again:

sudo apt install tree

That install is not a reason to use a GUI file manager.

Skip tree /, tree /etc, and tree of whole home for this practice.

Skip tree -a of home for this practice if that dumps .ssh. Prefer skip listing ~/.ssh.

When you are done practicing, throw away the practice files. Careful delete only. That is delete a file carefully:

rm -i ~/tree-me/a/b/hi.txt

Delete practice folders the same careful way after they are empty. Skip rm -rf.

Useful extras, still home only

Skip paths under /etc, SSH folders, or paths you don't own. Practice only in home.

Want depth limited so the tree stays short?

tree -L 2 ~/tree-me

-L 2 means two levels deep. Deeper folders stay hidden.

Want folders only, no files?

tree -d ~/tree-me

-d means directories only.

Skip GUI file managers for this practice. tree is enough for this look. Skip NAS browsers. This tree does not need a NAS.

Keep SSH on the house network: keep the computer on the house network. Don't forward port 22.

What this is not

This is not a list of one folder. That is see what's in a folder. It is not a search by name. That is find a file by name. It is not unpack of a zip. That is unpack a zip you already have.

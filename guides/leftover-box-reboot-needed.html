Notes / Getting started / See if a reboot is needed

Written 28 Aug 2026. This is a how-to, not a product card.

See if a reboot is needed

After weekly updates, check whether a reboot is needed before you buy a monitoring box.

Keep the computer updated says reboot only if the flag says so. This note is the quiet look that answers that. Debian and Ubuntu leave a small flag file when a reboot will finish the fixes. You are not guessing from a kernel line. You are reading the flag. You don't need a monitoring appliance for one flag.

Skip until the weekly habit exists

If you have never run the two update commands, start with keep the computer updated. If SSH from the couch is not working yet, that is SSH from the couch. Prefer this look right after an upgrade finishes, or any morning you wonder whether last week's fixes still need a restart. This note assumes you can log in from the couch.

What this is

A look, not a shopping trip. You are reading a reboot flag the computer already wrote. You are not buying a UPS, an N100, a mesh kit, or a monitoring box this morning. A reboot finishes some updates. A power-off for the night is different: shut down the computer without yanking the plug.

Ask if a reboot is needed

SSH in from the couch, then run:

test -f /var/run/reboot-required && echo needs reboot || echo no reboot needed

If you see needs reboot, a restart will finish the last fixes. If you see no reboot needed, leave it alone. Don't reboot every week on habit. Don't buy anything because the line printed once.

Optional: which packages asked

If the flag is there and you want the short list of packages that asked:

cat /var/run/reboot-required.pkgs

No file, or an empty look, is fine. The flag file is enough. Keep this note on yes or no.

If it needs a reboot

Finish with a clean restart:

sudo reboot

Wait a minute. Then is the computer still on?, log back in, and confirm the house jobs: after a reboot, check the computer still does its jobs. Failed jobs after that are see if any house jobs failed to start. Don't yank the cord for this. That is for a night you mean to power off: shut down the computer without yanking the plug.

What next

The weekly two commands stay keep the computer updated. When that habit is boring, later is let the computer apply weekly fixes without you (still leave automatic reboot off). How long it has been awake after a restart is see how long the computer has been awake. The first rule stays start with what you already have.

Skip

  • Skip if you have not run weekly updates yet. That is keep the computer updated.
  • Skip a reboot when the line says no reboot needed.
  • Skip a monitoring box, a UPS, or a new mini PC for this look.
  • Skip letting unattended upgrades reboot the computer by itself. That is still off in let the computer apply weekly fixes without you.
  • Skip a NAS for this look.

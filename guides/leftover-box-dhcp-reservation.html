Keep the computer on the same number

SSH and Pi-hole keep working after a reboot when the router always gives the computer the same address.

You already found the computer once. That was find the computer on the house network. Get the number first if you don't have it: see the computer's address on the house network. Confirm the path to the router: check that the computer can reach the house router. Write down the sticker: see the computer's hardware address. Then you SSHed with that number. After a reboot, the number may move. This note is the short generic pass. Why the number moves

The house router hands out addresses for a while, then may pick a new one when the computer comes back. You reboot after updates, or the power blips, and suddenly SSH from the couch fails with the number you wrote down. Find the computer works again, but you should not have to hunt every morning. Pi-hole is the same story: the house looks for it at the old number and ads come back.

What a DHCP reservation is

DHCP is how the router hands out numbers on the house network. A reservation means this computer always gets the same number. It still asks the router for an address. The router just always answers with the one you chose. You do the work on the router, not by typing a static address into Linux on the computer. Router menus call it Reserve, Always use this IP, or Static lease. Same idea.

Do it on the house router

Open a browser on your normal computer. Log into the house router with the address on the sticker, often 192.168.1.1 or 192.168.0.1. That password is on the sticker, or the one you set. Find the client list, device list, or DHCP list. That is the same list from find the computer on the house network.

Find the computer by name, by the number you already use for SSH, or by the hardware address from see the computer's hardware address. Choose Reserve, Always use this IP, or Static lease. Keep the number you already use. Don't invent a new one unless the old one is already taken. Save.

Then reboot the computer, or wait for the lease to renew. Reboot lives on shut down the computer without yanking the plug. When it is back, SSH again with that same number.

Check

From another computer on the house network, knock three times with the known number:

ping -c 3 192.168.1.50

Swap in your real number. Then SSH the way SSH from the couch taught you. If ping fails, see is the computer still on? before you touch the router again.

What next

If Pi-hole is not up yet, that is the first useful thing on the computer. If Pi-hole is already up, point the house at the ad block with that same address. Brand DNS menus: point common home routers at Pi-hole. If password SSH has been boring for a week, log in with a key, not the password every time. If the short name is still ugly, give the computer a name that sticks. If it is still on Wi-Fi, plug a cable: a cable beats Wi-Fi for the computer. Don't buy a NAS for this.

Skip

  • Skip this note if SSH already works every day with the same number, or if the reservation is already set.
  • Skip typing a static IP into Linux on the computer for a first pass. The reservation on the router is enough.
  • Skip a new router.
  • Skip buying a Pi-hole just for this.
  • Skip a managed switch for this.

Notes / Faster network / Check that the computer can reach the house router

Written 27 Aug 2026. This is a how-to, not a product card.

Check that the computer can reach the house router

Before you blame the switch or buy a new cable, ping the router from the computer.

Ping is a tiny "are you there?" check. The gateway (default route) is the house router's address on your network, the first hop out of the computer. You already know the computer's own number from see the computer's address on the house network. This note checks the path to the router.

Skip until SSH works

If you have never logged in from the couch, that is SSH from the couch. You can also type this at the keyboard. Prefer this look after a cable is plugged in and you know the address: a cable beats Wi-Fi for the computer, then see the computer's address on the house network. This note assumes you can log in from the couch, or sit at the keyboard.

What this is

A look, not a shopping trip. If ping to the router fails, fix the cable, Wi-Fi, or awake check before you buy a 2.5G switch. Start with is the computer still on? and a cable beats Wi-Fi for the computer. Don't buy a switch for a failed ping.

Find the router number

SSH in from the couch, or sit at the keyboard, then ask:

ip route

Point at the default via … line. That via address is the gateway (the house router). It often looks like 192.168.1.1 or 10.0.0.1.

Ask

Ping that gateway three times. Replace GATEWAY with the via number you just saw:

ping -c 3 GATEWAY

Three replies with times mean the computer can reach the router. 100% loss means the path is broken: cable, sleep, or wrong network. That is is the computer still on?, a cable beats Wi-Fi for the computer, or keep the computer on the house network.

Ping past the router

Only after the router replies. That look is its own note: check that the computer can reach the internet.

What next

Past the router: check that the computer can reach the internet. Cable speed: see the cable speed. Write down the hardware address: see the computer's hardware address. Keep the number stable: keep the computer on the same number.

Skip

  • Skip if SSH and the keyboard both fail. That is is the computer still on? or SSH from the couch.
  • Skip a new switch for a failed ping.
  • Skip forwarding port 22.
  • Skip buying a NAS for this look.
  • Skip Proxmox tonight. That is what a VM is, and when you don't need one.

Notes / Faster network / Move into a folder

Written 28 Aug 2026. This is a how-to, not a product card.

Move into a folder

After SSH works, change folders with cd. You don't need a file manager app for this.

SSH from the couch sits you in a folder. See what's in a folder lists the names in that folder. cd is change directory. It moves you into another folder so the next ls, nano, or copy lands where you meant. The computer does not need a desktop or a NAS for this one job.

Skip until SSH already works

SSH from the couch should already get you a prompt. If you only need names, that is see what's in a folder. If you only need to move a file, that is copy a file to the computer from your laptop. This note is how you sit in a different folder. Skip this whole note if you are still stuck on the first login.

What this is

cd changes the folder your next commands use. ls /etc can look at a folder without moving. After cd /etc, a plain ls lists that folder, and a filename with no path is in that folder. You are not measuring free disk. That is see if the computer still has room.

Move into a folder

SSH in. At the prompt, pick a folder you already saw with ls. A first login is usually home. Try the settings folder just to look:

cd /etc

If that folder is not there, the computer says no such file or directory. Check the name, or make a folder. That is not a reason to buy a NAS. A folder you copied into, if it exists:

cd ~/scripts

The tilde ~ is a short name for your home folder. Swap scripts for a folder you actually have.

See that you moved

After you change folders:

pwd

That prints the full path. The dedicated note is see which folder you are in. Then:

ls

You want the names for the folder you just named. Listing without moving is still see what's in a folder.

Go back home

Plain cd with no folder, or:

cd ~

Both put you in the login's home folder. That is the usual first-login folder. Optional check:

pwd

You want something like /home/you.

Go up one folder

Two dots mean the folder that holds this one:

cd ..

From /home/you that lands in /home. From /etc that lands in /, the root. Check with pwd again. You are only moving. Don't delete names you don't know.

Optional: the folder you just left

To bounce back to the folder you were in a moment ago:

cd -

That prints the path it moved to. Useful when you peeked at /etc and want home again without typing the long path. Skip this if the two-dot form already got you where you wanted.

What this is not

This move is not a backup. It is not a house share other computers browse. That is a folder the house can open. Copying one file from the laptop is copy a file to the computer from your laptop. Editing a file once you are in the folder is edit a file from the couch.

What next

Need only the full path after you move? See which folder you are in. Need a folder that is not there yet? Make a folder. Want the names in this folder? See what's in a folder. Need to change one of those files? Edit a file from the couch. Need the file on the laptop too? Copy a file to the computer from your laptop. Tired of retyping the same long line? Reuse a command you already typed. When key login is boring on every computer you use, turn off password login once the key works. Keep SSH on the house network: keep the computer on the house network. Don't forward port 22.

Skip

  • Skip if SSH still fails. Finish SSH from the couch first.
  • Skip buying a file manager, Midnight Commander, or a “cloud drive” app to change folders.
  • Skip cd / tonight and wandering the whole the computer. Home, one named folder, and two dots are enough.
  • Skip deleting names you don't know. Moving is the job.
  • Skip opening SSH to the internet so you can change folders from a coffee shop. That is keep the computer on the house network.

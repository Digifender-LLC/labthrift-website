Notes / Getting started / Keep the computer updated

Written 24 Aug 2026. This is a how-to, not a product card.

Keep the computer updated

Once a week, give the computer its fixes so SSH and Pi-hole are not sitting on last year's bugs. Skip this until next week if you just finished first weekend.

An update is the computer downloading those fixes. Two commands. That is the weekly job, not a shopping trip.

Skip this until next week

If you just finished your first weekend with the computer, that note already updates once. You can wait a week. Come back then.

SSH in, then two commands

From your normal computer, SSH from the couch. Then run two commands, one after the other.

Refresh the list of fixes:

sudo apt update

Install them:

sudo apt upgrade

Say yes to the upgrade prompt. If it asks about restarting services, yes is fine on a computer that is not a store.

Reboot only if it says so

Reboot only if the flag says so, or after a kernel line shows up. A kernel line is a core-of-the-OS fix. The quiet check is see if a reboot is needed. If that flag is set, reboot is the clean way to finish.

sudo reboot

Then find the computer on the house network and SSH back.

Don't turn on unattended-upgrades

Don't turn on unattended-upgrades this weekend. That is the setting that applies fixes by itself. One weekly habit is enough. When that habit is boring, the later note is let the computer apply weekly fixes without you.

What next

If the computer is a laptop, keep it awake when the lid closes. That is don't let the old laptop sleep. If it is still on Wi-Fi, plug a cable: a cable beats Wi-Fi for the computer. If weekly jobs wake at the wrong hour, set the computer clock to your house. If you have no second copy of the house folder, that is a backup of the house folder. When you're done for the night, don't yank the cord. That is shut down the computer without yanking the plug. After the upgrade, check the reboot flag: see if a reboot is needed. Apt refuses with a lock or interrupted dpkg? when weekly updates won't install. Apt does not refresh Pi-hole itself: keep Pi-hole updated. After a reboot, confirm SSH, ads, and the share still work: after a reboot, check the computer still does its jobs. After weekly updates leave installer files behind, clear old package downloads when the disk is tight. Don't buy a NAS.

Skip

  • Skip this note until next week if you just ran the first-weekend update.
  • Skip unattended-upgrades this weekend. Later is let the computer apply weekly fixes without you.
  • Skip a NAS, a new mini PC, and a new switch.

Notes / Faster network / See the computer's address on the house network

Written 27 Aug 2026. This is a how-to, not a product card.

See the computer's address on the house network

You need the computer's number before you reserve DHCP or SSH from another room.

The address (IP) is the computer's number on the house network, like a house number on the street. hostname -I prints it in one line. You need that number before you reserve DHCP or SSH from another room.

Skip until SSH works

If ping fails and SSH hangs, start with is the computer still on? If you have never logged in from the couch, that is SSH from the couch. You can also type this at the keyboard. Prefer this look after a cable is plugged in: a cable beats Wi-Fi for the computer. If Wi-Fi keeps waking up after a reboot, that is keep Wi-Fi off after a reboot. This note assumes you can log in from the couch, or sit at the keyboard.

What this is

A look, not a shopping trip. You need the computer's number to SSH from the couch later, to set a DHCP reservation (keep the computer on the same number), or to check the computer is on the house network (keep the computer on the house network). Don't buy a switch for this look.

Ask for the house number

SSH in from the couch, or sit at the keyboard, then ask:

hostname -I

One line of numbers. The first one that looks like 192.168.… or 10.… is usually the house address. Ignore long IPv6 strings for now unless that is all you see.

Optional clearer print

If you want a table of plugs instead of one line:

ip -brief addr

Point at the ethernet line (often a name that starts with en, or eth0) with UP and an inet address. Wi-Fi lines can wait if a cable is plugged in.

Write it down

Sticky note or phone. The next step to keep it stable is keep the computer on the same number. If the number keeps changing after a reboot, that reservation guide is the fix, not a new mini PC.

What next

Path to the router: check that the computer can reach the house router. Cable speed: see the cable speed. Hardware address: see the computer's hardware address. Same number after reboot: keep the computer on the same number. Cable: a cable beats Wi-Fi for the computer.

Skip

  • Skip if SSH and the keyboard both fail. That is is the computer still on? or SSH from the couch.
  • Skip a new switch for this look.
  • Skip forwarding port 22.
  • Skip buying a NAS for an address.
  • Skip Proxmox tonight. That is what a VM is, and when you don't need one.

Written 24 Aug 2026. This is a how-to, not a product card.

A file share

A folder on the old PC that the house can open from a laptop or a phone. You don't need a NAS for this.

A file share is a folder on this computer that phones and laptops can open like a USB drive on the network. Pi-hole can wait a week if you just put it on. This is the other small useful thing: a shared folder. Same computer. Same SSH from the couch.

What this is

A program called Samba. Free software that speaks the language Windows, Mac, and phones already use for shared folders. You don't buy a Synology for a folder of photos. The computer already has a disk.

This assumes Debian or Ubuntu Server, the OS from what OS to put on it, installed as in your first weekend. SSH in from the couch.

Make a folder

Pick one place. /srv/share is fine, or a folder in your home. Keep it simple. One share, named something obvious like photos or house.

sudo mkdir -p /srv/share

Install Samba

Samba is in the normal Debian and Ubuntu list. One command:

sudo apt install samba

Say yes. That is the whole install.

Tell Samba about the folder

The settings live in /etc/samba/smb.conf. Open that file and add a small block at the bottom. Swap youruser for the login you created at install, and the path if you used a different folder.

[photos]

path = /srv/share

browsable = yes

read only = no

valid users = youruser

Then set a share password for that same user:

sudo smbpasswd -a youruser

This password is for the share. It can match the Linux login, or it can be different. Samba keeps its own copy. If you forgot it later, set it again in set or change the house-share password.

Restart it

Samba only reads the file when you restart it.

sudo systemctl restart smbd

Open it from a laptop or a phone

Use the address from the first weekend, the same number you SSH to.

On Windows, open File Explorer and type \\lab-address\photos in the path bar. On a Mac, Finder → Go → Connect to Server, then smb://lab-address/photos. The longer laptop walk is open the house share from a laptop.

On a phone, the short path is open the house share from a phone, then save phone photos to the house share. iPhone uses the Files app. Samsung uses My Files. A Pixel needs a different file app. Same address, same share password.

If you cannot write

If you can see the folder but cannot drop a file in, the Linux folder owner is the usual culprit. Samba is using that same user, so that user has to own the folder. Run sudo chown youruser:youruser /srv/share and try again.

If the share is invisible

Ubuntu may have a firewall called ufw. If the share does not show up, check it with sudo ufw status. If ufw is on, allow Samba with sudo ufw allow Samba. If you turned that firewall on deliberately, the full path is turn on a simple firewall without locking yourself out, which has the Samba rule and the re-check together. Don't expose this to the internet. The share is for the house network only. If the share used to work and then vanished, that check is when the house share disappeared, check the computer.

What next

Leave it. Use the folder for a while. Open it from a laptop in open the house share from a laptop. Keep a drive letter or Finder Locations entry with map the house share as a drive. From a phone in open the house share from a phone. Away from home (Tailscale, no SMB on the router): open the house share from away. Or from a Chromebook in open the house share from a Chromebook. Need a separate folder (documents next to photos)? Add a second house share. Need a second person with their own login? Add another person to the house share. Check live connections with see who is using the house share. Someone should leave later: remove someone from the house share. If you forgot the share password, set or change the house-share password. If Finder, File Explorer, or the phone can't open it later, start with when the house share won't open. Opens and copies but photos crawl: when the house share is slow. If Samba stopped on an awake computer, when the house share disappeared, check the computer. After the house can open it, see if the computer still has room. If the system disk is small, park the share on a USB that stays plugged in: put the house folder on a USB disk. On a Mac, Time Machine can use a separate Samba share: back up a Mac to the house share with Time Machine. When you want a second copy of the house folder, that is a backup of the house folder (USB), or copy to another old computer. Not a NAS. Not RAID.

Optional: track the share name and who can open it in Lab plan — username + passkey, no email. Skip if you just want to keep reading.

Skip

  • Skip buying a NAS for a first folder. The disk already in the computer is enough.
  • Skip RAID.
  • Skip merging this with Pi-hole into a “homelab stack” on day one.
  • Skip exposing SMB to the internet.
  • Skip Synology or UGREEN until that disk is actually full.
  • Waiting a week after Pi-hole is fine. You can write this share now, or later. Both are the next step.

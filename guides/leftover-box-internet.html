Notes / Faster network / Check that the computer can reach the internet

Written 27 Aug 2026. This is a how-to, not a product card.

Check that the computer can reach the internet

Before you blame the computer or buy a mesh kit, ping a number past the house router.

You already reached the house router in check that the computer can reach the house router. This note asks a public number, not a website name. 1.1.1.1 is Cloudflare's public address. You are not switching DNS. You are asking if packets leave the house. A site name is a different look: look up a site name from the computer.

Skip until the router replies

If you have never logged in from the couch, that is SSH from the couch. You can also type this at the keyboard. If ping to the router already fails, fix that first: check that the computer can reach the house router. Prefer this look after a cable is plugged in: a cable beats Wi-Fi for the computer. This note assumes you can log in from the couch, or sit at the keyboard, and the router already replies.

What this is

A look, not a shopping trip. If the computer can ping the router but cannot ping a number past it, that is house internet, the ISP, or the router WAN. Not a new switch. Not a mesh kit. Don't buy Omada, UniFi, or a Protectli tonight.

Ask a public number

SSH in from the couch, or sit at the keyboard, then ask:

ping -c 3 1.1.1.1

Three replies with times mean packets leave the house. 100% loss, with the router still answering, means the computer is fine and the path past the router is not. Check the house phones. If they are also dead, that is the ISP or the modem, not a buy.

Optional second public number

If 1.1.1.1 is silent, try Google's public address:

ping -c 3 8.8.8.8

Some networks refuse ping to one of those numbers and still browse fine. If both are silent, but a phone on the same house network still loads sites, ICMP (the ping packet) may be blocked. That is not a dead computer. Try a name next: look up a site name from the computer. Don't buy a mesh kit for a blocked ping.

What the look means

Router works, public number works, names fail: that is DNS. See see which name server the computer is using, then look up a site name from the computer. Router works, public number fails, phones are also dead: wait on the ISP. Don't buy a 2.5G switch. Router ping already failed: go back to check that the computer can reach the house router. Ads came back while names still work: that is when ads come back, check the ad block.

What next

Path to the router: check that the computer can reach the house router. Cable speed: see the cable speed. Names: look up a site name from the computer. Which name server: see which name server the computer is using.

Skip

  • Skip if the router ping already fails. That is check that the computer can reach the house router.
  • Skip a mesh kit for a failed public ping.
  • Skip a new switch for this look.
  • Skip forwarding port 22.
  • Skip buying a NAS for this look.
  • Skip Proxmox tonight. That is what a VM is, and when you don't need one.

Written 29 Aug 2026. This is a how-to, not a product card.

See where a command lives

After SSH works, ask where a command lives with command -v so you know if nano or python is installed before you chase a missing package. You don't need a software store for this.

Reuse a command you already typed flips back through lines you already ran. Tonight you only need one answer: is this tool on the computer, and where? command -v prints the path for a name you type. Blank output means it is not there. You are still only looking. The computer does not need a desktop, a software store, or a new mini PC for this one job.

Skip until SSH already works

SSH from the couch should already get you a prompt. If you only need the names in a folder, that is see what's in a folder. If you only need to reuse a line you typed earlier, that is reuse a command you already typed. Skip this whole note if you only need a house share other computers browse. That is a folder the house can open.

What this is

command -v means "command, verbose path." You can keep calling it "where does this live." You give one short name. If that name is a real program, it prints the full path, something like /usr/bin/nano. If the name is missing, the window stays blank and the command exits with nothing useful. That blank line is the useful answer. It is not a package install. It is not a search of every file. That is find a file by name. One name, one path, or nothing.

Ask where a practice command lives

SSH in. Pick a tool you already used. ls is a safe first try:

command -v ls

You want a path, usually /usr/bin/ls or /bin/ls. That means the computer already has it.

Try the editor next:

command -v nano

A path means edit a file from the couch can open. A blank window means nano is not installed yet. Install only that one tool if you need it:

sudo apt install nano

Then ask again. You want a path this time.

Try a name that is probably missing, so you see the blank case:

command -v this-is-not-a-real-tool

You want a blank window. That is the whole first-night trick: path means go, blank means stop and install (or pick a different tool).

Useful extras, still looking only

Need several names in one go?

command -v ls nano python3

Each name that exists prints its path on its own line. Missing names stay quiet. That is enough to see which of three tools are already on the computer.

Some guides still say which. It often works the same way:

which nano

Prefer command -v tonight. It is built into the shell, so you are not depending on an extra package. If which itself is missing, that is not a reason to buy anything. Stick with command -v.

If you see command not found for everyday tools like ls or cp, install the usual tools, then try again:

sudo apt install coreutils

Debian and Ubuntu Server usually already have them. That install is not a reason to buy a software store.

When you are done looking, you don't need to delete anything. This note only prints paths.

What this is not

This is not a search for a file by name. That is find a file by name. It is not a dump of a file. That is read a file without opening the editor. It is not a list of folders. That is see what's in a folder. It is not installing a package store or a "software center." One missing tool is sudo apt install for that one name. It is not a house share other computers browse. That is a folder the house can open.

What next

Need the short cheat sheet for a tool you found? Ask a command what it does. Need the editor and it was missing? Install nano, then edit a file from the couch. Need a short line without the editor? Put a short line into a file. Need names in a folder again? See what's in a folder. Need a shortcut? Make a shortcut. Need to flip back through lines you already typed? Reuse a command you already typed. When a house job broke, look at the computer's own diary: when something broke, look at the log. When key login is boring on every computer you use, turn off password login once the key works. Keep SSH on the house network: keep the computer on the house network. Don't forward port 22.

Skip

  • Skip if SSH still fails. Finish SSH from the couch first.
  • Skip printenv as tonight's job. Printenv prints environment (HOME and PATH), not which: see HOME and PATH.
  • Skip buying a software store, Softaculous, or a new mini PC because one name printed blank. Install that one tool, or pick a tool that is already there.
  • Skip type -a, whereis, and deep PATH edits tonight. command -v is enough to see if the name exists.
  • Skip installing random packages from a blog just because the window was blank. Prefer the tool names you already met on Labthrift.
  • Skip SSH settings, /etc/shadow, and anything under /etc/ssh. Looking at trusted laptop keys is see which laptop keys the computer already trusts.
  • Skip opening SSH to the internet so you can hunt commands from a coffee shop. That is keep the computer on the house network.

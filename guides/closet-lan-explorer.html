Map a drop before you blame the switch: Klein VDV526-100

Map an RJ45 drop before you blame the switch. One button says pass, miswire, open, short, or shield, and the remote stores in the tester so there is no second box to lose. It will not tone a wall, and it will not certify Cat6A.

SKU VDV526-100. LAN Explorer. Tests RJ11 / RJ12 / RJ45. CAT3, CAT5e, CAT6 / 6A (wiremap, not certification). LEDs: Pass, Miswire, Open-Fault, Short-Fault, Shield. Remote stores in the tester. One 9 V included. Auto power-off. Maker length to 1000 ft / 305 m. 4.9 × 2.5 × 1.3 in, 5.0 oz / 142 g with battery and remote. 2 ft drop rating. Replacement remote VDV999-150. UPC 092644692246. This is not VDV226-110 and not VDV427-300.

Home Depot internet #309925931, 23 Aug 2026: $29.97. Local stock was 0 on that snap. Print the live tag. Skip no-name Amazon “network tester” kits that don't name Klein or a remote that stores in the body.

Skip

Skip this if you have not terminated anything yet. That is the punch-down or the pass-thru crimp. Skip no-name Amazon kits with no named remote. Skip a Fluke DSX for twelve closet drops. Skip treating this as a Cat6A certifier; it is a wiremap. Skip buying VDV500-123 and hoping it maps RJ45 without a toner. Used eBay lots are out.

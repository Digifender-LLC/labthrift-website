Cheap four-port Amazon barebone; treat the listing as hostile: CWWK

A cheap four-port Amazon barebone for a house firewall. Same port count as Protectli, worse firmware and support. Often ships with no RAM. Treat the listing as hostile.

A cheap four-port Amazon barebone. Treat the listing as hostile. 2.5G means faster house ethernet. Amazon B0CL5SBWCJ: CWWK N100, DDR5, 0 RAM / 0 SSD, 4× i226-V 2.5G, AES-NI, OPNsense-marketed. Live 22 Aug 2026 (Add to cart present). Amazon B0CG8JBDCD is a different SKU: CWWK N305 8C/8T, 6× i226-V, fanless, barebone, DDR5 to 32 GB. Use that in an N305 compare, not as the N100 review unit. Maker F12 / F10 N100–N305 4× i226, DDR5. F10 “from $245.80” / $393.33 on cwwk.com, config-dependent.

The roundup already said BIOS is the gamble. That line is the whole post. Buyer must add ≥16 GB DDR5. Barebone 0 GB is an 8 GB trap waiting to happen. CWWK is not Topton; don't assume BIOS files interchange (CWWK’s own post). Pay-for-coreboot contrast: VP2430e vs CWWK.

Skip

Skip stuffing 8 GB into a barebone “to try it.” Skip Topton AliExpress boxes with no stable ASIN. Skip treating CWWK BIOS as Protectli coreboot. If you want the warrantable N150 4-NIC, VP2430e. Class decision: dual-LAN vs 4-NIC.

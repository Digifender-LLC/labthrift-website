Notes / Faster network / Read a file without opening the editor

Written 29 Aug 2026. This is a how-to, not a product card.

Read a file without opening the editor

After SSH works, print a file with cat so you can read it without opening nano. Short files only. You don't need a file viewer for this.

See what's in a folder gives you names. Tonight you want the words inside one of those names. cat prints a file straight into the SSH window. Useful after edit a file from the couch, so you can check the save without opening the editor again. It does not need a desktop, a file manager, or a NAS for this one job.

Skip until SSH already works

SSH from the couch should already get you a prompt. If you only want the names in a folder, that is see what's in a folder. If you want to change a line, that is edit a file from the couch. If a house job broke and you need the computer's own log, that is when something broke, look at the log. Skip this whole note if you only need a house share other computers browse. That is a folder the house can open.

What this is

cat prints a file. You run it on the computer, after SSH. The file stays on disk. You are only looking. It does not open an editor. That is nano. It does not list folder names. That is ls. It does not pull the computer's system journal. That is when something broke, look at the log. One path, same computer, words on the screen.

Print a short file

SSH in. If you don't already have a throwaway file, make one in home:

echo 'hello' > ~/hello.txt

Then print it:

cat ~/hello.txt

You want the same line you wrote. Swap the name for yours. A short text file is the right first try. Photos, zip files, and programs will print junk. Skip those.

See that you did not change it

List it:

ls -lh ~/hello.txt

You want the same name, a tiny size, and today's date if you just made it. Print it a second time if you want. The computer showed you the file. It did not edit it. Need a line changed? That is edit a file from the couch.

Optional: first lines only

A long file can flood the SSH window. If that happens, Ctrl+C stops the print. For a peek at the top instead:

head -n 20 ~/hello.txt

That peek is also its own note: see the start of a file.

That prints the first twenty lines and stops. Need the last lines instead? That is see the end of a file. Need the whole long file one screen at a time? That is read a file one screen at a time. Optional line numbers on a short file:

cat -n ~/hello.txt

Practice in home. Skip SSH settings and anything under /etc/shadow.

What this is not

This is not an editor. That is edit a file from the couch. It is not a list of names. That is see what's in a folder. It is not the computer's system journal. That is when something broke, look at the log. It is not a look at which laptop keys the computer already trusts. That is see which laptop keys the computer already trusts. It is not a house share other computers browse. That is a folder the house can open.

Skip

  • Skip if SSH still fails. Finish SSH from the couch first.
  • Skip nano if you only want to look. That tool is for changing a line.
  • Skip cat on photos, zip files, programs, or a file so long it never stops. Use see the start of a file for a peek, or read a file one screen at a time for the whole long file.
  • Skip buying a file viewer, a “cloud IDE,” or a NAS to read one text file.
  • Skip SSH settings, /etc/shadow, and anything under /etc/ssh. Looking at trusted laptop keys is see which laptop keys the computer already trusts.
  • Skip opening SSH to the internet so you can read files from a coffee shop. That is keep the computer on the house network.

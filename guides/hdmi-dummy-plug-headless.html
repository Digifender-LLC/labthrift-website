HDMI dummy plug for a headless mini PC

A $16 HDMI plug so a closet mini PC thinks a monitor is attached. Skip if you already have a screen in there. EDID is the tiny handshake a PC uses to know a display is plugged in.

Labthrift use is remote desktop and BIOS-via-KVM. Pair with a $100 HDMI+USB KVM if you also need BIOS. The host is in the N100 note.

Notes / Faster network / See which folder you are in

Written 29 Aug 2026. This is a how-to, not a product card.

See which folder you are in

After SSH works, print the full path with pwd so you know where ls and nano will land. You don't need a file manager app for this.

See what's in a folder lists names. Move into a folder changes the folder. Tonight you only need the answer to “where am I?” pwd prints the full path of the folder you are sitting in. You are still only looking. The computer does not need a desktop, a file manager, or a NAS for this one job.

Skip until SSH already works

SSH from the couch should already get you a prompt. If you only need the names in this folder, that is see what's in a folder. If you want to sit in a different folder, that is move into a folder. Skip this whole note if you only need a house share other computers browse. That is a folder the house can open.

What this is

pwd means print working directory. It prints the full path of the folder your next commands use. You run it on the computer, after SSH. It does not list the names in that folder. That is ls. It does not move you. That is cd. It does not make a folder. That is mkdir. One short command, same computer, the full path.

Print the path

SSH in. At the prompt:

pwd

You should see a full path that starts with a slash, often something like /home/you on a first login. That is the whole first-night trick. The tilde ~ is a short name for that home folder. pwd always prints the long form.

Then list the names in that same folder:

ls

Those names belong to the path pwd just printed. That list job is see what's in a folder.

Useful extras, still looking only

Peek at another folder, then check where you landed:

cd /etc

pwd

You want /etc. You are only looking. Don't edit files there from this note. Go back home:

cd ~

pwd

You want something like /home/you again. Moving is move into a folder. Tonight pwd is only the check after you move.

If you see command not found, install the usual tools, then try again:

sudo apt install coreutils

Debian and Ubuntu Server usually already have it. That install is not a reason to buy a file manager.

Skip extra flags tonight. Plain pwd is enough for tonight.

What this is not

This is not a list of names. That is see what's in a folder. It is not a move into another folder. That is move into a folder. It is not making a folder. That is make a folder. It is not free disk left. That is see if the computer still has room. It is not a hunt for a file by name. That is find a file by name. It is not a house share other computers browse. That is a folder the house can open.

What next

Need the names in this folder? See what's in a folder. Need to sit somewhere else? Move into a folder. Need a folder that is not there yet? Make a folder. Need an empty file in this folder? Make an empty file. Need one short line without the editor? Put a short line into a file. Need to change a file here? Edit a file from the couch. Need a file from the laptop instead? Copy a file to the computer from your laptop. When a house job broke, look at the computer's own diary: when something broke, look at the log. When key login is boring on every computer you use, turn off password login once the key works. Keep SSH on the house network: keep the computer on the house network. Don't forward port 22.

Skip

  • Skip if SSH still fails. Finish SSH from the couch first.
  • Skip printenv as tonight's job. Printenv prints environment (HOME and PATH), not pwd: see HOME and PATH.
  • Skip buying a file manager, Midnight Commander, or a “cloud drive” app to see which folder you are in.
  • Skip pwd flags and symlink puzzles tonight. The plain path is the job.
  • Skip SSH settings, /etc/shadow, and anything under /etc/ssh. Looking at trusted laptop keys is see which laptop keys the computer already trusts.
  • Skip opening SSH to the internet so you can check folders from a coffee shop. That is keep the computer on the house network.

When the router password won't work

The gateway login page loads, but sticker, app, or old password fails. Try the right account and maker app before a factory reset. A reset wipes DNS and reservations.

Blank tab or timeout instead of a login form? That is when the home router page won't open. Pi-hole admin on the old PC? That password is separate: change the Pi-hole admin password. This note is only when the router or ISP gateway form is already on screen and the password still fails.

Skip until the login form is on screen

If the browser never shows a username or password field, fix reachability first with when the home router page won't open. Don't hold the reset pin because a bookmark timed out. Don't type the Pi-hole password into the gateway, or the gateway sticker into Pi-hole.

What this is

Home gateways keep an admin password for the small web UI (and often a maker app). The sticker on the bottom is a factory guess. Someone may have changed it in the app years ago. ISP gateways sometimes want the account PIN or an app login instead of the sticker. Wrong box, wrong account name, Caps Lock, and a password manager auto-fill for a different site are the cheap mistakes.

Step 1: confirm you are on the gateway, not Pi-hole

Look at the URL and the branding. Gateway login is usually http:// plus the Default Gateway number from the laptop (no /admin). Pi-hole shows its own logo and path like /admin or http://pi.hole/admin. If you see Pi-hole, stop. Use when the Pi-hole admin page won't open or change the Pi-hole admin password.

Step 2: try sticker, then the password you set

Flip the gateway. Read the printed username and password (or QR that opens the maker app). Common sticker pairs: admin / printed string, blank user with only a password, or a Wi-Fi password that is not the admin password. Type it by hand once. Skip password-manager fill on the first try.

If you changed the admin password in the past and still remember it, use that. The sticker stops working the moment someone saved a new admin password. Wi-Fi passphrase and admin password are often different. The network password reconnects phones. The admin password opens this page.

Step 3: use the maker or ISP app when the page rejects you

eero, Google Nest / Google Wifi, Orbi, some ASUS and TP-Link Deco packs, and many ISP gateways want the phone app or an ISP account more than the sticker. Open the app while you are on house Wi-Fi. Sign in with the email or ISP login that set the kit up. Admin on the web UI may be locked until the app says so.

ISP rental gateways (Xfinity, Spectrum, AT&T, Verizon, and friends) often ignore the bottom sticker. Use the ISP account PIN, the app, or the password the tech left on the install sheet. Calling the ISP for a temporary admin unlock is slower than a reset, and it does not wipe your LAN DNS.

Step 4: match what the form says

User not found / wrong usernameTry admin, blank user, or the exact sticker username. Case matters on some boxes.
Locked / too many attemptsWait ten minutes. Power-cycle the gateway once. Do not reset yet.
App works, web UI failsUse the app for DNS and reservation menus for now. Web admin may be off or cloud-only on mesh kits.
Pi-hole login brandingWrong host. Use the Default Gateway number, not the old PC. See Step 1.
Captive portal / ISP sign-inYou are not on the local admin page. Get the gateway number from the laptop and open http plus that number on house Wi-Fi: when the home router page won't open.

Step 5: what a factory reset actually costs

A reset (hold the pin, or the app's "erase network") puts the gateway back to sticker defaults. It also clears:

  • LAN / DHCP DNS pointed at the old PC (ads come back until you set it again)
  • DHCP reservations (SSH and Pi-hole may move to a new number)
  • Wi-Fi name and password (every phone and laptop must rejoin)
  • Port forwards, guest network tweaks, and parental rules you forgot about

After a reset you are in the same recovery shape as a tech swap: when the ISP swaps your router. Re-find the computer, re-point DNS, re-do the reservation. Prefer the ISP unlock or maker app recovery when you can. Reset is the last move, not the first.

Step 6: if you still choose to reset

Write down the Wi-Fi name and password you want afterward. Hold the reset pin per the sticker (often 10 seconds until LEDs blink). Wait for Wi-Fi to return. Join with the sticker Wi-Fi password. Open the gateway with the sticker admin password over http. Set a new admin password you will store somewhere other than a sticky note on the modem.

Then restore house lab settings: DNS menus in point common home routers at Pi-hole, reservation in keep the computer on the same address on common routers, and find the computer again if the number moved: find it on the house network. Ads still everywhere after that? When ads come back.

What this is not

This is not a blank tab when the gateway never loads. That is when the home router page won't open. It is not the Pi-hole admin password on the old PC. It is not a reason to buy a mesh kit because you forgot a password. It is not forwarding the gateway admin page to the internet so you can "fix it later."

What next

Once you are in, leave a password manager entry labeled gateway admin (not Wi-Fi). Point DNS if that was the job: point common home routers at Pi-hole. Keep the computer on one address: keep the computer on the same address on common routers. Page never loaded at all? When the home router page won't open.

Optional: jot the gateway admin hint (not the password) in Lab plan — username + passkey, no email. Skip if you just want to keep reading.

Skip

  • Skip a factory reset before sticker, the password you set, and the maker or ISP app.
  • Skip typing the Wi-Fi passphrase into the admin form (and the other way around).
  • Skip typing the Pi-hole password into the gateway.
  • Skip buying a new router because the sticker stopped working after someone changed admin.
  • Skip exposing gateway admin on the public internet.
  • Skip this if the login page never appears. Use the blank-tab walk instead.

Your first weekend

Install the OS, give it a name, plug it into the wall, and make sure you can reach it from the couch.

This is a weekend, not a shopping trip. You already have the computer. You already picked an OS, or you can pick one on what OS to put on it. The job is to get it on, named, and reachable.

1. Backup anything you care about

Copy off photos, school papers, or a game save you still want. Full walk: copy your files off before you wipe. If the computer is empty, skip this step.

2. Make a USB installer

Download the Ubuntu Server or Debian ISO from the official site. Write it to a USB stick with balenaEtcher or Ventoy. An 8 GB stick is enough. You probably already have one. Step-by-step flash: make a boot USB for the install. Boot menu keys: boot the old PC from the USB stick. Got it from Marketplace? Wipe first: wipe a Marketplace PC before you install.

3. Boot it from the USB

Most PCs: tap F12 or F10 at power-on and pick the stick. Brand keys and stuck-stick fixes: boot the old PC from the USB stick. Install to the internal disk. One disk is fine. Take the defaults.

4. Give it a name and a user

Pick a name you will remember: lab, closet, office. Create a user. Don't skip the SSH server checkbox if Ubuntu Server offers it. SSH is a way to type commands on that computer from your normal one, over the network.

5. Plug ethernet if it has a port

Wi-Fi is fine. Plug a cable if the computer has a port. It drops fewer connections overnight. No cable nearby? The walk is put the old PC on house Wi-Fi.

6. Find its address

Look on your router’s device list, or on the computer itself (hostname -I, or the installer summary). You don't need a fancy static IP yet.

7. Connect from the couch

From your normal computer, connect. Windows: Windows Terminal or PowerShell, ssh you@that-address. Mac or Linux: Terminal, same command. The first time it will ask to trust this machine. Say yes.

8. Update

On Debian or Ubuntu, run sudo apt update && sudo apt upgrade. Reboot if it asks.

9. Leave it on

That is the lab. Don't buy a rack, a switch, or a NAS this weekend.

What next

Find its number on the house network first. That is find it on the house network. Then SSH from the couch. If it is a laptop, keep it awake when the lid closes: don't let the laptop sleep. Later, put a small useful thing on this same computer. The ad-block one is the first useful thing. A file share can wait a week. Next week, keep the computer updated. Not a shopping trip.

Skip

  • Skip Kubernetes until it has been on a week.
  • Skip Docker Swarm until it has been on a week.
  • Skip buying a new mini PC until it has been on a week.
  • Skip a 10G card until it has been on a week.
  • Skip a UPS until it has been on a week.

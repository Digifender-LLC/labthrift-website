Notes / Faster network / Read a file one screen at a time

Written 29 Aug 2026. This is a how-to, not a product card.

Read a file one screen at a time

After SSH works, open a file with less so a long file does not flood the window. Space turns the page. q leaves. You don't need a file viewer for this.

Read a file without opening the editor prints the whole file at once. That is fine for a short note. A long file fills the SSH window and keeps going. less shows one screen, then waits. You are still only looking. It does not need a desktop, a file viewer, or a NAS for this one job.

Skip until SSH already works

SSH from the couch should already get you a prompt. If the file is short, that is read a file without opening the editor. If you want to change a line, that is edit a file from the couch. If a house job broke and you need the computer's own diary, that is when something broke, look at the log. Skip this whole note if you only need a house share other computers browse. That is a folder the house can open.

What this is

less is a pager. You run it on the computer, after SSH. The file stays on disk. You are only looking. It does not print everything at once. That is cat. It does not open an editor. That is nano. It does not pull the computer's system journal. That is when something broke, look at the log. One path, same computer, one screen at a time.

Open a file that is longer than the window

SSH in. Make a throwaway file that is long enough to page:

seq 1 80 > ~/lines.txt

Then open it:

less ~/lines.txt

The computer takes over the SSH window. You see the first screen of numbers, and a colon at the bottom. That colon means less is waiting. You are still in the file. You have not left SSH.

A real file that is safe to practice on:

less /etc/services

That list is long and already on Debian and Ubuntu. You are only looking. Don't edit it.

Turn the page, then leave

While less is open:

  • Space turns the next page.
  • b goes back one page.
  • q leaves and gives you the prompt back.

That is the whole first-night trick. Optional search: type /, then a word, then Enter. n jumps to the next match. q still leaves. If you forget the keys, h opens a help screen. q leaves that too.

If you see command not found, install the pager, then try again:

sudo apt install less

Debian and Ubuntu Server usually already have it. That install is not a reason to buy a file viewer.

What this is not

This is not an editor. That is edit a file from the couch. It is not a dump of the whole file. That is read a file without opening the editor. It is not the computer's system journal. That is when something broke, look at the log. It is not a list of names. That is see what's in a folder. It is not a house share other computers browse. That is a folder the house can open.

What next

Need a short file printed all at once? Read a file without opening the editor. Need the names first? See what's in a folder. Forgot which folder holds the file? Find a file by name. Need to change a line? Edit a file from the couch. Need a spare before you edit? Copy a file without leaving the computer. Need the throwaway gone for real? Delete a file carefully. Need a file from the laptop instead? Copy a file to the computer from your laptop. Tired of retyping the same long line? Reuse a command you already typed. When key login is boring on every computer you use, turn off password login once the key works. Keep SSH on the house network: keep the computer on the house network. Don't forward port 22.

Skip

  • Skip if SSH still fails. Finish SSH from the couch first.
  • Skip cat on a file that never stops. That dump is read a file without opening the editor, and it is the wrong tool for a long file.
  • Skip nano if you only want to look. That tool is for changing a line.
  • Skip less on photos, zip files, or programs. Those print junk. A text file is the job.
  • Skip buying a file viewer, a “cloud IDE,” or a NAS to read one text file.
  • Skip SSH settings, /etc/shadow, and anything under /etc/ssh. Looking at trusted laptop keys is see which laptop keys the computer already trusts.
  • Skip opening SSH to the internet so you can read files from a coffee shop. That is keep the computer on the house network.

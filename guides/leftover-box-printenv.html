Written 31 Aug 2026. This is a how-to, not a product card.

See HOME and PATH

After uname, print HOME and PATH with printenv so login environment makes sense. You don't need extra software for this.

See kernel name and architecture printed the kernel. Tonight you list your login environment: printenv. Printenv prints HOME, PATH, USER, SHELL. You are still only practicing in home on the computer. It does not need extra system software, htop, Grafana, or a NAS for this one job.

Skip until SSH already works

SSH from the couch should already get you a prompt. If kernel name is what you want, that is see kernel name and architecture. If language and region are what you want, that is see language and region. If login name is what you want, that is see the login name. If user number and groups are what you want, that is see user number and groups. Skip echo $HOME as tonight's job. That is echo, not printenv.

What this is

printenv prints environment. You type printenv plus a name. HOME is your home folder. PATH is where the shell looks for commands. USER is the login name again. SHELL is which prompt program. It is not uname. Uname prints the kernel. It is not echo. Echo prints words you type. Skip echo $HOME as the job.

Practice printenv in home

SSH in. Make sure home is where you sit:

pwd

You want a path that ends in your login name. If not:

cd ~

Ask for HOME:

printenv HOME

You should see a path that ends in the login name (same idea as pwd). That path is HOME. That is enough for tonight. Practice only in home.

Debian and Ubuntu usually already have printenv. Don't make apt the job. If printenv is missing:

sudo apt install coreutils

Then stop. That install is not the lesson.

Useful extras, still home only

Ask for PATH:

printenv PATH

Ask for USER:

printenv USER

Ask for SHELL:

printenv SHELL

Optional: print the whole environment:

printenv

That can be a long list. You can stop at HOME and PATH. Skip editing /etc/environment, /etc/profile, or ~/.bashrc tonight.

What this is not

This is not uname. That is see kernel name and architecture. It is not id. That is see user number and groups. It is not whoami. That is see the login name. It is not pwd. That is see which folder you are in. It is not echo. That is put a short line into a file. It is not OS name. That is see which OS the computer is already running. It is not opening SSH to the internet. That is keep the computer on the house network. Don't forward port 22.

What next

Need language and region? See language and region. Need the terminal name? See the terminal name. Need kernel name? See kernel name and architecture. Keep SSH on the house network: keep the computer on the house network. Don't forward port 22.

Skip

  • Skip if SSH still fails. Finish SSH from the couch first.
  • Skip echo $HOME and echo $PATH as tonight's job. That is echo, not printenv.
  • Skip editing /etc/environment, /etc/profile, or ~/.bashrc tonight.
  • Skip uname, id, whoami, pwd, and locale as tonight's job. Those pages already exist.
  • Skip files under /etc, SSH folders, or paths you don't own. Practice only in home.
  • Skip rm -rf. Careful delete only: delete a file carefully.
  • Skip opening SSH to the internet so you can do this from a coffee shop. That is keep the computer on the house network. Don't forward port 22.

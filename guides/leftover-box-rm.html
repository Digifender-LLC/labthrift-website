Notes / Faster network / Delete a file carefully

Written 29 Aug 2026. This is a how-to, not a product card.

Delete a file carefully

After SSH works, delete one file with rm -i. The computer asks before it goes. Skip rm -rf. You don't need a NAS for this.

Rename or move a file keeps the bytes under a new name. Tonight the throwaway practice file can go away for real. rm is remove. One file, home folder, ask first. Useful after copy a file without leaving the computer left a spare you no longer want. The computer does not need a trash can app, a desktop, or a NAS for this one job.

Skip until SSH already works

SSH from the couch should already get you a prompt. If you want the file under a better name and still on disk, that is rename or move a file. If you want a second copy and the original to stay, that is copy a file without leaving the computer. If the file is still only on the laptop, that is copy a file to the computer from your laptop. Skip this whole note if you only need a house share other computers browse. That is a folder the house can open.

What this is

rm deletes a file. You run it on the computer, after SSH. The name is gone. There is no Recycle Bin on a typical server. That is why tonight we type rm -i. The -i means ask. It does not rename. That is mv. It does not leave a spare. That is cp. It does not talk to the laptop. That is scp. One path, same computer, file gone.

Make a throwaway, then delete it

SSH in. Make a practice file in home if you don't already have one:

echo 'delete me' > ~/delete-me.txt

See that it is there:

ls ~/delete-me.txt

Then ask before delete:

rm -i ~/delete-me.txt

The computer should ask something like remove regular file. Type y and Enter if that is the file you meant. Type n if it is not. Swap the name for yours. Practice in home. Skip anything under / or /etc.

See that it is gone

List home:

ls ~

You don't want delete-me.txt any more. Optional exact check:

ls ~/delete-me.txt

You want “No such file or directory.” That is success. The computer removed the file. It did not hide it in a trash folder.

Optional: one empty folder

Empty folders are a different tool. If you made a practice folder with make a folder and it is empty:

rmdir ~/notes-practice

rmdir only works when the folder has nothing inside. If it complains the directory is not empty, list it with see what's in a folder, move or delete the files first, then try again. Skip rm -rf. That flag can wipe a whole tree with no useful undo, and it is not tonight’s job.

What this is not

This is not a rename that keeps the bytes. That is rename or move a file. It is not a second copy. That is copy a file without leaving the computer. It is not a file from the laptop. That is copy a file to the computer from your laptop. It is not emptying the disk of old logs. That is clear old logs when the disk is tight. It is not a checked backup. That is a backup of the folder.

What next

Need a spare before you delete? Copy a file without leaving the computer. Need the name to change instead? Rename or move a file. Need the names again? See what's in a folder. Need a folder for practice files? Make a folder. Need to read a file without opening the editor? Read a file without opening the editor. Need to change a line first? Edit a file from the couch. Need a file from the laptop instead? Copy a file to the computer from your laptop. Tired of retyping the same long line? Reuse a command you already typed. When key login is boring on every computer you use, turn off password login once the key works. Keep SSH on the house network: keep the computer on the house network. Don't forward port 22.

Skip

  • Skip if SSH still fails. Finish SSH from the couch first.
  • Skip mv if you want the file gone. That tool keeps the bytes under a new name.
  • Skip rm -rf, rm -rf /, and anything under /etc or SSH settings.
  • Skip buying a NAS, a “cloud drive,” or a trash-can app to delete one practice file.
  • Skip deleting the only copy of something you care about. Make a copy or a backup first.
  • Skip opening SSH to the internet so you can delete files from a coffee shop. That is keep the computer on the house network.

Written 29 Aug 2026. This is a how-to, not a product card.

Copy a file without leaving the computer

After SSH works, copy a file with cp so you can edit a spare without wrecking the original. You don't need a NAS for this.

Copy a file to the computer from your laptop is the laptop-to-computer path. Tonight you are already on the computer. cp is copy. It makes a second file from one that is already there. Useful before edit a file from the couch, so a bad save does not eat the only copy. It does not need a desktop, a NAS, or a cloud drive for this one job.

Skip until SSH already works

SSH from the couch should already get you a prompt. If the file is still on the laptop, that is copy a file to the computer from your laptop. If you need a folder for the spare to land in, that is make a folder. Skip this whole note if you only need a house share other computers browse. That is a folder the house can open.

What this is

cp copies a file to another name or folder. You run it on the computer, after SSH. It does not talk to the laptop. That is scp. It does not share the copy with phones. That is Samba. It does not measure free disk. That is see if the computer still has room. Two names, same computer.

Make a spare with a new name

SSH in. If you don't already have a throwaway file, make one in home:

echo 'hello' > ~/hello.txt

Then copy it to a second name:

cp ~/hello.txt ~/hello-copy.txt

The first path is the file you already have. The second path is the spare. Swap the names for yours. A short name with no spaces is easier to type later.

See that both are there

List home:

ls ~

You want hello.txt and hello-copy.txt. Optional look at size and date:

ls -lh ~/hello.txt ~/hello-copy.txt

The sizes should match. Optional peek at the spare without opening the editor:

cat ~/hello-copy.txt

You want the same line you wrote. Now you can edit the spare: edit a file from the couch. The original stays put.

Copy into a folder

Need a folder first? Make a folder. Then keep the same filename and drop the copy inside:

cp ~/hello.txt ~/notes/

The trailing slash on notes/ is a reminder that the last thing is a folder. List it:

ls ~/notes

You want hello.txt in that folder. A full second path also works if you want a different name in there:

cp ~/hello.txt ~/notes/hello-keep.txt

Optional: ask before overwriting

If the spare name already exists, a plain cp replaces it with no useful undo. Ask first:

cp -i ~/hello.txt ~/hello-copy.txt

The computer will wait for a yes if that second name is already taken. Type n if you did not mean to replace it. Skip cp -r tonight unless you are copying one small folder you made. Skip copying anything under / or /etc. Home is the practice place.

What this is not

This copy lives on the computer. It is not a shortcut. That is make a shortcut. It is not a compare of two files. That is see whether two files are the same. It is not a file from the laptop. That is copy a file to the computer from your laptop. It is not a house share other computers browse. That is a folder the house can open. It is not a checked backup. That is a backup of the folder. Free disk left is still see if the computer still has room.

When key login is boring on every computer you use, turn off password login once the key works. Keep SSH on the house network: keep the computer on the house network. Don't forward port 22.

Skip

  • Skip if SSH still fails. Finish SSH from the couch first.
  • Skip scp for a file that is already on the computer. That tool is the laptop path.
  • Skip buying a NAS, a “cloud drive,” or a file manager to duplicate one file.
  • Skip cp -r /, anything under /etc, or SSH settings tonight.
  • Skip opening SSH to the internet so you can copy files from a coffee shop. That is keep the computer on the house network.

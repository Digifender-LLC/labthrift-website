Notes / Better Wi-Fi / When ads come back, check the ad block

Written 26 Aug 2026. This is a how-to, not a product card.

When ads come back, check the ad block

The computer is awake, but banners are back. Check that Pi-hole is still answering before you buy a mesh kit or blame the router.

Ads coming back usually means the house stopped asking the computer for names, or Pi-hole stopped answering. You don't need a new mesh kit for this. You don't need to redo the whole router. Check the computer that already did the job once.

Skip until the computer is awake

If ping and SSH fail, fix that first in is the computer still on? This note assumes the computer answers SSH from the couch.

Skip until Pi-hole was working once

If you never installed Pi-hole, start with the first useful thing on the computer. If you never pointed the house at that computer, do that in point the house at the ad block. This note is for the morning when ads came back after it already worked.

Is Pi-hole still running?

SSH from the couch, then:

pihole status

Or if that command is missing:

sudo systemctl is-active pihole-FTL

You want active / listening. If it is not, restart it:

sudo systemctl restart pihole-FTL

Or, if the pihole CLI is there, pihole restartdns. Then open the admin page in a browser the way the first useful thing on the computer taught. Sites should load. A lot of the banners should not.

Is the house still pointed at the computer?

On one phone or laptop, check that DNS is still the address. That is the router LAN DNS you set, or the device DNS you set for a test. If the router forgot the setting after a power blink, set it again: point the house at the ad block. A DHCP reservation helps the number stay put after a reboot.

Firewall can hide DNS

If ufw is on and no names resolve, allow port 53 as in turn on a simple firewall without locking yourself out. House network only. Don't forward port 53 to the internet.

What next

If blocking works but one site you need is broken, see when a site won't load after Pi-hole. Leave it. After install, change the printed Pi-hole admin password. Skip a mesh kit. Skip Unbound. Skip buying a Raspberry Pi. If a restart did not help, that is when something broke, look at the log. If the share also vanished, see the Samba section in turn on a simple firewall without locking yourself out or start from a file share on the computer. If names fail or ads come back only on the computer, see which name server the computer is using.

Skip

  • Skip if the computer is off.
  • Skip if Pi-hole was never installed.
  • Skip a mesh kit for ad block.
  • Skip Unbound on day one.
  • Skip opening Pi-hole to the internet.
  • Skip a second box.

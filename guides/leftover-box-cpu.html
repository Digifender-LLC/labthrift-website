See how many workers the computer already has

Before you buy a tiny computer, check how many workers the computer already has.

The computer already has workers. A worker is one CPU core, the computer's ability to do more than one job at once. House ad block and a file share barely need two. Memory room is a different look: see if the computer still has free memory. A busy program is see what is keeping the computer busy. You don't need an N100 this morning just because the laptop is old.

Skip until SSH works

If ping fails and SSH hangs, start with is the computer still on? If you have never logged in from the couch, that is SSH from the couch. Prefer this look after the computer is doing real work, before you shop: start with what you already have. This note assumes you can log in from the couch.

What this is

A look, not a shopping trip. You are counting workers on the computer you already have, before you buy a tiny computer. Two workers still run the first lab. Four is plenty. You are not buying an N100, an N150, or a Protectli tonight.

Ask how many workers

SSH in from the couch, then run:

nproc

nproc prints one number. That number is how many workers the computer can use right now. 2 is an old laptop or a small office box. 4 or more is a typical old desktop. House ad block plus a file share is fine on 2. Don't buy a mini PC for a 2.

Optional chip name

If you want the computer's chip name, not just the count:

lscpu | grep 'Model name'

That line is the chip name. Enough to see it is not a 15-year-old box you should retire tonight. Keep this light. Don't shop from a model string. Don't install extra tools for this look.

If the number is small

Two workers still do the first lab. If the computer feels slow, check see if the computer still has free memory and see what is keeping the computer busy before you shop. RAM and one busy copy squeeze an old laptop more often than a low worker count. Whether the computer can run a pretend computer is see if the computer can run a pretend computer. A later tiny computer is a tiny computer you can leave on, when the computer is actually in the way. Skip buying one this morning because nproc printed 2.

Skip

  • Skip if SSH fails. That is is the computer still on? or SSH from the couch.
  • Skip buying an N100 because nproc printed 2.
  • Skip stacking a movie library, a VM, and Pi-hole on two workers, then blaming the computer.
  • Skip a NAS for this look.
  • Skip Proxmox tonight. That is what a VM is, and when you don't need one.

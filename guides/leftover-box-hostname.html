Written 25 Aug 2026. This is a how-to, not a product card.

Give the computer a name that sticks

Ping and SSH are easier if the computer has a short name. lab works. Set it so the name survives a reboot.

closet or office work too. Letters and numbers, no spaces. A hostname is the computer's name on the house network. Is the computer still on? tells you to ping that name. Your first weekend names it during install, then people forget. This note is hostnamectl, the command that writes the name so it comes back after a reboot.

Skip this if the name is already good

On the computer, ask for the name:

hostname

If it already prints lab, or a name you recognize and like, you are done. You don't need this note.

Set the name so it survives a reboot

On Debian or Ubuntu, as in what OS to put on the computer, set the name with hostnamectl. That writes the computer's name so it comes back after a reboot.

sudo hostnamectl set-hostname lab

Swap lab for closet or office if you picked one of those. Then log out and SSH back, or reboot. Reboot lives on shut down the computer without yanking the plug. If you were already rebooting after keep the computer updated, that reboot is enough.

Check from the couch

From another computer on the house network, knock three times. That is is the computer still on?:

ping -c 3 lab

If ping still needs the number, the house router has not learned the name yet. Use the address from find the computer on the house network. A new router will not help. Some phones find lab.local. Some don't. Don't buy a Pi-hole just for naming. If Pi-hole is already house DNS, a Local DNS record is the reliable house-wide name: add a local name in Pi-hole.

What next

If ping lab works on some devices and not others, give the house a Local DNS name that every Pi-hole client can resolve: add a local name in Pi-hole. If ping lab works, you are done naming. If ads came back this morning, or SSH hangs, that is is the computer still on?. If the computer is still on Wi-Fi, plug a cable: a cable beats Wi-Fi for the computer. Don't buy a NAS.

Skip

  • Skip this note if hostname already prints lab or a name you like.
  • Skip a new router.
  • Skip buying a Pi-hole just to make lab resolve.

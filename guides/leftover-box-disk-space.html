Notes / File storage / See if the computer still has room

Written 26 Aug 2026. This is a how-to, not a product card.

See if the computer still has room

After the house folder is working, check that the computer is not filling up. Photos stop copying when the disk is full. You don't need a NAS for this look.

This is a look, not a shopping trip. The house folder is already on the computer. You are asking whether that disk still has room, before a phone copy fails. How big the disk already is, before you shop, is a different look: see how big the disk already is.

Skip until the share works

If phones and laptops cannot open the house folder yet, stop. Fix that first. That is a file share on the computer. Disk room does not help a share that is not working.

What this is

The computer has one main disk. House photos go on that same disk. An old laptop disk fills faster than people expect. This is a look, not a shopping trip. You are not buying a file box this weekend.

Ask how full it is

From the couch, SSH in, then ask:

df -h

df is the computer reporting how full its disk is. Point at the line that ends in /. That is the disk. When Use% is in the 80s, it is time to clean. 100% is why copies failed.

See what the house folder is using

The share lives at /srv/share/. Ask how big that folder is, not the whole disk:

sudo du -sh /srv/share

That number is the shared folder size. Old Downloads and a full Trash on an old laptop also eat room. If this computer is a laptop that still has a desktop user, you can look at those two:

du -sh ~/Downloads ~/.local/share/Trash 2>/dev/null

If it is filling

Delete obvious junk. Empty the Trash. Clear old Downloads you don't need. If a copy fails while free space still looks fine, check file slots: when copies fail but free space looks fine. If you want the next question (where the room went), that is see which folders are eating the disk. After weekly updates, clear leftover package downloads: clear old package downloads when the disk is tight. Old diary pages: clear old logs when the disk is tight. Don't buy a NAS because an old laptop disk is small. A second copy on a USB disk you already have is a backup of the house folder. A real file box is later: a first file box (NAS).

If the system disk is the problem, move the live share onto a USB that stays plugged in: put the house folder on a USB disk.

Skip

  • Skip this note if the share is not working yet.
  • Skip a NAS for this look.
  • Skip a new internal drive this weekend.
  • Skip filling the old laptop with a movie library.

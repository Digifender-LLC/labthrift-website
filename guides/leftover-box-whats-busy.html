See what is keeping the computer busy

The computer feels slow. Check which program is using the CPU before you buy a new mini PC.

The computer feels slow. Memory room is a different look: see if the computer still has free memory. Disk room is see if the computer still has room. This note asks which program is using the computer's worker (the CPU) right now.

Skip until SSH works

If ping fails and SSH hangs, start with is the computer still on? If you have never logged in from the couch, that is SSH from the couch. Prefer this look after you already checked memory: see if the computer still has free memory. This note assumes you can log in from the couch.

What this is

A look, not a shopping trip. One busy program can make SSH feel late. A copy, a weekly update, or a movie job you started can sit at the top and then go away. Don't buy a mini PC for a one-off copy. Don't kill programs tonight.

Ask which program is busy

SSH in from the couch, then run:

ps aux --sort=-%cpu | head

ps is the computer listing running programs. | head keeps the first few lines so you don't get a wall of text. The first line is labels. Point at %CPU (how busy that program is) and COMMAND (the name). The top names after the labels are the busy ones right now.

A copy often shows rsync. A weekly fix often shows apt or unattended-upgrades. Those can wait. If the same name stays at the top while you are not copying or updating, that program is the squeeze.

Optional load hint

If you want a second hint that the computer is piled up:

uptime

That is the same optional look as see if the computer still has free memory. Load numbers that stay high with nothing happening can mean the computer is working too hard. Keep this light. You don't need to learn load averages in depth tonight.

If something is busy

Wait out a copy or a weekly update. Don't kill processes tonight. Don't stack a movie library, a VM, and Pi-hole on a 4 GB old laptop. If memory is also tight, that is still see if the computer still has free memory. A later mini is a tiny computer you can leave on, when you actually need it. Skip buying one this morning if the busy name was a one-off job.

How many workers the computer already has: see how many workers the computer already has. Skip a new mini PC this morning if the computer was only busy for a copy.

Skip

  • Skip if SSH fails. That is is the computer still on? or SSH from the couch.
  • Skip killing programs tonight.
  • Skip installing a prettier process viewer for this look.
  • Skip a new mini PC for a one-off copy.
  • Skip a NAS for this look.
  • Skip Proxmox tonight. That is what a VM is, and when you don't need one.

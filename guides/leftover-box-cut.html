Notes / Faster network / Pull one column

Written 30 Aug 2026. This is a how-to, not a product card.

Pull one column

After SSH works, pull one column with cut so a mixed line is easier to scan. You don't need a file manager for this.

Drop duplicate lines dropped copies. Tonight you pull one column out of a line: cut. Cut pulls one field out of a mixed line. Start with a tiny fruit list with commas. You are still only looking. The computer does not need a file manager for this one job.

Skip until SSH already works

SSH from the couch should already get you a prompt. If duplicates dropped are what you want, that is drop duplicate lines. If characters changed are what you want, that is change characters. If columns side by side are what you want, that is join columns side by side.

What this is

cut pulls one column. You type cut -d, -f1, then a file. -d, means comma is the split. -f1 is field 1. It prints that column. It does not rewrite the file. It is not paste. Paste joins columns from two files. It is not tr. Tr changes characters. Skip ls -lh piped into cut. ls -lh pads spaces, and cut on one space lands in the wrong fields.

Practice cut in home

SSH into the computer. Make a tiny practice file:

printf 'apple,red\nbanana,yellow\npear,green\n' > ~/fruit.csv

cat ~/fruit.csv

Pull fruit:

cut -d, -f1 ~/fruit.csv

You want apple, then banana, then pear. Need colors instead?

cut -d, -f2 ~/fruit.csv

You want red, then yellow, then green. That is enough for tonight. Practice only in home.

Debian and Ubuntu usually already have cut. Don't make apt the job. If cut is missing:

sudo apt install coreutils

Then stop. That install is not the lesson.

When you are done, throw the practice files away. Careful delete only. That is delete a file carefully. Skip rm -rf.

rm ~/fruit.csv

Useful extras, still looking only

Need fruit and color together?

cut -d, -f1,2 ~/fruit.csv

Need first letters, not columns?

cut -c1-5 ~/fruit.csv

-c means characters from the start of the line, commas too. That look is optional.

Need first letters from folder names, without a file in the middle?

ls | cut -c1-4

That bar is send output into another command. Skip ls -lh piped into cut. Padded spaces land in the wrong fields. That trap is not tonight.

What this is not

This is not search. That is find a word in a file. It is not order. That is put lines in order. It is not copies dropped. That is drop duplicate lines. It is not paste. That is join columns side by side. It is not tr. That is change characters. It is not a house share. That is a folder the house can open. It is not opening SSH to the internet. That is keep the computer on the house network.

What next

Need columns side by side? Join columns side by side. Need characters cleaned? Change characters. Need copies dropped? Drop duplicate lines. Need lines in order? Put lines in order. Keep SSH on the house network: keep the computer on the house network. Don't forward port 22.

Skip

  • Skip if SSH still fails. Finish SSH from the couch first.
  • Skip cut over files you care about, paths under /etc, and SSH settings. Practice only files you just made in home.
  • Skip awk, xargs, and huge logs tonight. Cut by itself is enough for a first look.
  • Skip cut on ls -lh spaces. Skip cut piped into rm.
  • Skip SSH settings, /etc/shadow, and anything under /etc/ssh. Looking at trusted laptop keys is see which laptop keys the computer already trusts.
  • Skip files under /etc, SSH folders, or paths you don't own. Practice only in home.
  • Skip rm -rf. Careful delete only: delete a file carefully.
  • Skip opening SSH to the internet so you can do this from a coffee shop. That is keep the computer on the house network. Don't forward port 22.
